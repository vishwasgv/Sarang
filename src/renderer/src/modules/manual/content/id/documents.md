# Manajemen Dokumen

Sarang memungkinkan Anda melampirkan file sungguhan — perjanjian hasil pindai, tanda terima PO yang ditandatangani, gambar X-ray, ekspor CAD — langsung ke catatan yang menjadi pemiliknya, di sebagian besar bagian aplikasi: Faktur, Pesanan Pembelian, Pelanggan, Pemasok, Pengeluaran, Pesanan Produksi, dan (untuk jenis usaha yang berlaku) Revisi Gambar, Kunjungan Lokasi, Kasus Hukum, Tugas Kepatuhan, Penugasan, Pengajuan ROC, Rapat Dewan, Catatan Kunjungan, Rencana Perawatan, Pesanan Tes Lab, Item Pemesanan Sewa, Janji Temu, dan Kandidat.

## Melampirkan file ke catatan

Tidak ada langkah "unggah" terpisah — buka catatan spesifik (faktur, kasus hukum, pemesanan sewa, dan seterusnya) dan gunakan kontrol **Lampirkan file** miliknya sendiri untuk memilih file dari dialog. File tersebut disalin ke penyimpanan Sarang sendiri dan ditautkan ke catatan itu persis; file asli di komputer Anda tidak tersentuh dan dapat dipindahkan atau dihapus setelahnya tanpa memengaruhi salinan yang disimpan Sarang.

## Menjelajahi setiap file terlampir

Buka **Dokumen** dari sidebar untuk melihat setiap file yang terlampir di mana pun dalam aplikasi dalam satu tempat — bukan hanya yang terkait dengan catatan yang sedang Anda lihat. Cari berdasarkan nama file, atau filter berdasarkan jenis catatan tempatnya terlampir, menggunakan dropdown. Setiap baris menampilkan ikon file (berdasarkan jenis — gambar, spreadsheet, PDF, atau umum), jenis catatan yang menjadi pemiliknya, ukurannya, dan kapan dilampirkan.

Ketuk ikon tautan eksternal untuk membuka file di aplikasi mana pun yang biasa digunakan komputer Anda untuk jenis file tersebut. Ketuk ikon tempat sampah untuk menghapusnya — ini hanya menghapus lampirannya (dan salinan file milik Sarang sendiri), tidak pernah menghapus catatan asli tempatnya terlampir.
