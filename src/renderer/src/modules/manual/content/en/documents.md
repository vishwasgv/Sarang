# Document Management

Sarang lets you attach real files — a scanned agreement, a signed PO acknowledgement, an X-ray image, a CAD export — directly to the record they belong to, across most parts of the app: Invoices, Purchase Orders, Customers, Suppliers, Expenses, Production Orders, and (for the business verticals where it applies) Drawing Revisions, Site Visits, Legal Cases, Compliance Tasks, Engagements, ROC Filings, Board Meetings, Visit Notes, Treatment Plans, Lab Test Orders, Rental Booking Items, Appointments, and Candidates.

## Attaching a file to a record

There's no separate "upload" step — open the specific record (an invoice, a legal case, a rental booking, and so on) and use its own **Attach** control to pick a file from a dialog. The file is copied into Sarang's own storage and linked to that exact record; the original file on your computer is untouched and can be moved or deleted afterward without affecting the copy Sarang keeps.

## Browsing every attached file

Open **Documents** from the sidebar to see every file attached anywhere in the app in one place — not just the ones tied to the record you happen to be viewing. Search by file name, or filter by the type of record it's attached to, using the dropdown. Each row shows the file's icon (by type — image, spreadsheet, PDF, or generic), which kind of record it belongs to, its size, and when it was attached.

Tap the external-link icon to open a file in whatever application your computer normally uses for that file type. Tap the trash icon to remove it — this only removes the attachment (and Sarang's own copy of the file), never the original record it was attached to.
