# வழிகாட்டி: ஒன்றுக்கு மேற்பட்ட கணினிகளில் Sarang பயன்படுத்துதல்

சில கடைகளில் இரண்டு மூன்று பேர் ஒரே நேரத்தில் வேலை செய்ய வேண்டியிருக்கும்: ஒருவர் கவுண்டரில், ஒருவர் கொள்முதலில், ஒருவர் கணக்குகளைப் பார்ப்பதில். Sarang இதை உங்கள் சொந்தக் கடையின் நெட்வொர்க்கில் செய்ய முடியும். இணையம் வழியாக எதுவும் செல்லாது.

## இது எப்படி வேலை செய்கிறது

- ஒரு கணினி அனைத்துத் தரவையும் வைத்திருக்கும். அதற்குப் பெயர் **சர்வர்**. கடை நேரத்தில் அதை இயக்கத்தில் வைத்து Sarang-ஐத் திறந்து வையுங்கள்.
- மற்ற கணினிகள் **கிளையன்ட்கள்**. அவற்றில் வணிகத் தரவு இருக்காது. சர்வரில் உள்ள தரவை அவை காட்டி மாற்றும்.
- கணினிகளுக்கிடையே செல்வது அனைத்தும் நீங்கள் தேர்ந்தெடுக்கும் **பகிரப்பட்ட ரகசியக் குறியீட்டால்** மறைகுறியாக்கப்படும். நீங்கள் இயக்கும் வரை இது அணைந்திருக்கும்.

## உங்களுக்கு என்ன தேவை

- எல்லாக் கணினிகளும் கடையின் ஒரே நெட்வொர்க்கில் (ஒரே Wi-Fi அல்லது ஒரே கேபிள் நெட்வொர்க்).
- போதுமான **இருக்கைகள்** கொண்ட உரிமம். கடைக் கணினி ஒரு இருக்கையாகக் கணக்கிடப்படும், ஒரே நேரத்தில் உள்நுழையும் ஒவ்வொரு மற்றக் கணினியும் இன்னொரு இருக்கையைப் பயன்படுத்தும். இலவச சோதனையில் இரண்டு கணினிகள் அனுமதிக்கப்படும், நீங்கள் முயன்று பார்க்கலாம். இருக்கைகள் சேர்க்க உரிமத் திரையில் உள்ள முகவரிக்கு எழுதுங்கள்.

## சர்வரை அமைக்கவும் (தரவை வைத்திருக்கும் கணினி)

1. உரிமையாளராக உள்நுழையுங்கள். **Settings → Business features → Multi-user** செல்லுங்கள்.
2. **இந்தக் கணினி தரவை வைத்திருக்கிறது (சர்வர்)** தேர்ந்தெடுங்கள்.
3. காட்டப்படும் **முகவரி** (உதாரணம் 192.168.1.10:47821) மற்றும் **பகிரப்பட்ட ரகசியக் குறியீடு** குறித்துக்கொள்ளுங்கள். ரகசியக் குறியீட்டை எப்போது வேண்டுமானாலும் **புதிய ரகசியக் குறியீட்டை உருவாக்கு** மூலம் மாற்றலாம்.
4. **சேமித்து Sarang-ஐ மீண்டும் தொடங்கு** அழுத்துங்கள்.
5. வேறொரு கணினி இணைய முடியாவிட்டால், இந்தக் கணினியின் Windows ஃபயர்வாலில் தனிப்பட்ட நெட்வொர்க்குகளுக்கு Sarang-ஐ அனுமதியுங்கள்.

## ஒவ்வொரு கிளையன்ட் கணினியையும் அமைக்கவும்

1. கணினியில் Sarang-ஐ நிறுவித் திறவுங்கள்.
2. உள்நுழைவுப் பக்கத்தில் **கணினி இணைப்பு அமைப்புகள் (பல கணினிகள்)** அழுத்துங்கள்.
3. **இந்தக் கணினி வேறொரு கணினியுடன் இணைகிறது (கிளையன்ட்)** தேர்ந்தெடுங்கள். சர்வரின் முகவரியையும் பகிரப்பட்ட ரகசியக் குறியீட்டையும் உள்ளிட்டு, **இணைப்பைச் சோதி** அழுத்தி, பிறகு **சேமித்து Sarang-ஐ மீண்டும் தொடங்கு** அழுத்துங்கள்.
4. உங்கள் சொந்தப் பயனர்பெயர், கடவுச்சொல்லுடன் உள்நுழையுங்கள். **Settings → Users**-இல் ஒவ்வொருவருக்கும் பயனர்பெயர் உருவாக்குங்கள், அப்போது ஒவ்வொரு விற்பனையிலும் மாற்றத்திலும் யார் செய்தார் என்று தெரியும்.

## சேர்ந்து வேலை செய்தல்

- ஒவ்வொருவருக்கும் தனி உள்நுழைவும் தனி அனுமதிகளும் உண்டு.
- இருவர் ஒரே கணத்தில் சேமித்தால், ஒருவர் மற்றவருக்காகச் சிறிது நேரம் காத்திருப்பார். விலைப்பட்டியல் எண்கள் போன்றவை ஒருபோதும் மீண்டும் வராது. இருவர் கடைசிப் பொருளை விற்றால், ஒரு விற்பனை மட்டுமே நடக்கும்.
- ஒருவர் வாடிக்கையாளர், சப்ளையர் அல்லது பொருளைத் திருத்தத் திறக்கும்போது, அதே பதிவைத் திறக்கும் மற்றவர்களுக்கு **"… இதை மற்றொரு கணினியில் திறந்து வைத்திருக்கிறார்"** என்று தெரியும், அது மூடும் வரை அவர்களால் சேமிக்க முடியாது.
- மற்றொரு கணினி தரவை மாற்றும்போது ஒரு சிறிய குறிப்பு வரும்: **"… மற்றொரு கணினியில் சில தரவை மாற்றினார். புதுப்பி."** புதியதைப் பார்க்கப் புதுப்பி அழுத்துங்கள்.
- சர்வரில் உள்ள **Settings → Business features → Multi-user** யார் இணைந்திருக்கிறார்கள் என்று காட்டி, ஒரு கணினியின் இணைப்பைத் துண்டிக்க அனுமதிக்கும்.

## சர்வர் கணினியில் மட்டுமே நடப்பவை

காப்புப்பிரதி மற்றும் மீட்பு, கோப்புகளை இறக்குமதி செய்தல், பயிற்சி, உரிமத்தைச் செயல்படுத்தல், வட்டிலிருந்து ஆவணங்களைத் திறத்தல், சமையலறைச் சீட்டு அச்சிடல் ஆகியவை சர்வர் கணினியில் நடக்கும். கிளையன்ட் கணினி விலைப்பட்டியல்களைத் தன் சொந்த அச்சுப்பொறியில் அச்சிட்டு, அறிக்கைகளை (Excel, PDF, CSV) தன் சொந்த வட்டில் சேமிக்கும்.

## நல்ல பழக்கங்கள்

- சர்வரை நிலையான மின்சாரத்தில் வைத்து, சர்வரில் தினமும் காப்புப்பிரதி எடுங்கள். சர்வர் அணைந்திருந்தால் கிளையன்ட்கள் வேலை செய்ய முடியாது.
- தரவுக் கோப்பை மற்றக் கணினிகளுக்கு நகலெடுக்காதீர்கள், ஒரே கோப்பை நெட்வொர்க் வழியாக இரண்டு கணினிகளிலிருந்து திறக்காதீர்கள். இந்த வசதியையே பயன்படுத்துங்கள். ஒரு கோப்பை இரண்டு கணினிகளிலிருந்து திறந்தால் அது சேதமடையலாம்.
- பகிரப்பட்ட ரகசியக் குறியீட்டை ரகசியமாக வைத்திருங்கள். யாராவது கடையை விட்டுச் சென்றால், **புதிய ரகசியக் குறியீட்டை உருவாக்கு** அழுத்தி, புதியதை மற்றக் கணினிகளில் உள்ளிடுங்கள்.
