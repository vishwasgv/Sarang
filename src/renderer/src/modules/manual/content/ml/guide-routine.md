# ഗൈഡ്: ദിവസേന, ആഴ്ചയിൽ, മാസത്തിലെ ദിനചര്യ

ആലോചിക്കാതെ പിന്തുടരാവുന്ന ഒരു ചെക്ക്‌ലിസ്റ്റ്. നിങ്ങളുടെ ബിസിനസിന് ബാധകമായവയ്ക്ക് അടയാളമിടുക.

## ദിവസവും (10 മിനിറ്റ്)

**രാവിലെ**
- **ഡാഷ്‌ബോർഡ്** തുറക്കുക. അലേർട്ടുകളും (കുറഞ്ഞ സ്റ്റോക്ക്, കിട്ടാനുള്ളത്, വരാനുള്ള ഓർമ്മപ്പെടുത്തലുകൾ) ഇന്നലത്തെ വിൽപ്പനയും നോക്കുക. **Customise** (മുകളിൽ വലത്) നിങ്ങൾ ഉപയോഗിക്കാത്ത ഭാഗങ്ങൾ മറയ്ക്കുന്നു, **Add your own tile** ഈ ആഴ്ചത്തെ ചെലവ് പോലെ നിങ്ങൾക്ക് പ്രധാനമായ സംഖ്യ കാണിക്കുന്നു; രണ്ടും ഈ കമ്പ്യൂട്ടറിൽ നിങ്ങളുടെ ലോഗിനായി ഓർത്തുവയ്ക്കുന്നു.
- **മണി** ക്ലിക്ക് ചെയ്യുക. ഓരോ അലേർട്ടും അത് ഏതിനെക്കുറിച്ചാണോ ആ സ്ക്രീൻ തുറക്കുന്നു.
- **WhatsApp Reminders**: ഇന്ന് നൽകേണ്ടത് അയയ്ക്കുക (*Guide: Reminders and Alerts* കാണുക).
- Ask Sarang: "എന്റെ ശ്രദ്ധ എന്തിനാണ് വേണ്ടത്?"

**പകൽ സമയത്ത്**
- **ബില്ലിംഗ്**-ൽ വിൽക്കുക. മറ്റൊരു ഉപഭോക്താവ് വന്നാൽ വിൽപ്പന ഹോൾഡ് ചെയ്യുക.
- പേയ്മെന്റ് വരുമ്പോൾ തന്നെ രേഖപ്പെടുത്തുക (ഇൻവോയ്സ് സ്ക്രീൻ → Record Payment).
- സാധനം വരുമ്പോൾ വാങ്ങൽ ഓർഡറിൽ **Receive Stock** ചെയ്യുക (അല്ലെങ്കിൽ ഓരോ വരിയും ഒരു ഉൽപ്പന്നവുമായി ബന്ധിപ്പിച്ച് GRN പോസ്റ്റ് ചെയ്യുക).

**അടയ്ക്കുമ്പോൾ**
- **Accounting → ക്യാഷ് ക്ലോസ്**: പണം എണ്ണി, Sarang പ്രതീക്ഷിക്കുന്നതുമായി താരതമ്യം ചെയ്ത്, വ്യത്യാസം രേഖപ്പെടുത്തുക.
- ആ ദിവസത്തെ **റിപ്പോർട്ടുകൾ → Sales** നോക്കുക.

## ആഴ്ചയിൽ

- **റിപ്പോർട്ടുകൾ → Outstanding**: ആർക്ക് എത്ര കാലമായി നിങ്ങൾക്ക് നൽകാനുണ്ട്. ഏറ്റവും പഴയവർക്ക് ഓർമ്മപ്പെടുത്തലുകൾ അയയ്ക്കുക.
- **Purchases → Purchases Overview**: അടുത്ത 7 ദിവസത്തിനുള്ളിൽ അടയ്ക്കേണ്ട ബില്ലുകൾ. **Supplier Bills → Overdue** ഫിൽട്ടർ; പേയ്മെന്റുകൾ ആസൂത്രണം ചെയ്യുക. ഈ ആഴ്ച നടത്തിയ വിതരണക്കാരുടെ പേയ്മെന്റുകൾ രേഖപ്പെടുത്തുക.
- **ഇൻവെന്ററി → Low Stock**: വാങ്ങൽ ഓർഡറുകൾ ഉണ്ടാക്കുക (അല്ലെങ്കിൽ ഇൻവെന്ററി സ്ക്രീനിൽ **Generate Reorder POs** ഉപയോഗിക്കുക).
- **ക്വട്ടേഷനുകൾ → Expired** ഫിൽട്ടർ: കാലാവധി കഴിഞ്ഞവ പിന്തുടരുക അല്ലെങ്കിൽ അടയ്ക്കുക.
- നിങ്ങൾ എന്ത് വാങ്ങി എന്നറിയാൻ **റിപ്പോർട്ടുകൾ → Purchase Register** നോക്കുക.
- ഓട്ടോമാറ്റിക് ബാക്കപ്പ് ഉപയോഗിക്കുന്നില്ലെങ്കിൽ ബാക്കപ്പ് എടുക്കുക (ക്രമീകരണങ്ങൾ, ബാക്കപ്പ്).

## മാസത്തിൽ

- മാസത്തേക്ക് **റിപ്പോർട്ടുകൾ → Profit and Loss**, **Trial Balance**.
- **റിപ്പോർട്ടുകൾ → Tax Report / GSTR-1 / GSTR-3B Preview / GST Net Payable & Input Credit** (അല്ലെങ്കിൽ ഇന്ത്യയ്ക്ക് പുറത്ത് **VAT / Sales Tax Return**) നിങ്ങളുടെ അക്കൗണ്ടന്റിന് അയയ്ക്കുക, അല്ലെങ്കിൽ റിട്ടേൺ തയ്യാറാക്കാൻ ഉപയോഗിക്കുക. GST ബിസിനസുകൾക്ക് **Accounting → GST Return Files**-ൽ GSTR-1, GSTR-3B ഫയലുകൾ തയ്യാറാക്കാനും വാങ്ങലുകൾ പോർട്ടലിന്റെ GSTR-2B യുമായി ഒത്തുനോക്കാനും കഴിയും.
- **Bank Account** ബാങ്ക് സ്റ്റേറ്റ്‌മെന്റുമായി ഒത്തുനോക്കുക (**Accounting → Bank Accounts**-ൽ ബാങ്ക് അക്കൗണ്ട് തുറന്ന്, തുടർന്ന് **Reconciliation**).
- **Supplier Payments** വിതരണക്കാർ നിങ്ങൾ നൽകാനുണ്ടെന്ന് പറയുന്നതുമായി പരിശോധിക്കുക (ഓരോ വലിയ വിതരണക്കാരന്റെയും പേജ് തുറക്കുക).
- ശമ്പളം നടത്തുക (**People & Payroll → ശമ്പളപ്പട്ടിക**), ജീവനക്കാരുടെ ഹാജരും അവധിയും രേഖപ്പെടുത്തുക.
- മാസത്തെ **ചെലവുകൾ** പരിശോധിച്ച് രസീതുകളുമായി ഒത്തുനോക്കുക.
- വേഗത്തിൽ വിറ്റുപോകുന്ന ചില ഇനങ്ങൾ എണ്ണി വ്യത്യാസം **Adjust stock** ഉപയോഗിച്ച് തിരുത്തുക, അല്ലെങ്കിൽ വ്യത്യാസ റിപ്പോർട്ട് വേണമെങ്കിൽ പൂർണ്ണ **Stock Counts** സെഷൻ നടത്തുക.
- ജീവനക്കാർ സമർപ്പിച്ച **expense claims** രേഖപ്പെടുത്തി അംഗീകരിച്ച് തിരികെ നൽകുക.
- **Balance Sheet** ഒത്തുവരുന്നുണ്ടോ എന്ന് പരിശോധിച്ച് Ask Sarang-നോട് "എന്റെ കണക്കുകൾ ഒത്തുവരുന്നുണ്ടോ?" എന്ന് ചോദിക്കുക.
- **ബാക്കപ്പ്** എടുത്ത് ഒരു പകർപ്പ് രണ്ടാമത്തെ ഡ്രൈവിലോ പെൻ ഡ്രൈവിലോ സൂക്ഷിക്കുക.

## വർഷത്തിൽ

- നിങ്ങളുടെ അക്കൗണ്ടന്റ് സ്ഥിരീകരിച്ചാൽ കഴിഞ്ഞ വർഷം ലോക്ക് ചെയ്യുക (Ledger Settings, ലോക്ക് തീയതി).
- **Fixed Assets, വർഷാവസാന ക്ലോസ്**: മൂല്യത്തകർച്ച പോസ്റ്റ് ചെയ്ത് വർഷം അടയ്ക്കുക (ആ അധ്യായം കാണുക).
- Sarang ലൈസൻസ് കാലഹരണപ്പെടും മുമ്പ് പുതുക്കുക (ക്രമീകരണങ്ങൾ → ലൈസൻസ്). കാലഹരണപ്പെട്ടാലും എല്ലാം കാണാനും പ്രിന്റ് ചെയ്യാനും എക്സ്പോർട്ട് ചെയ്യാനും ബാക്കപ്പ് എടുക്കാനും കഴിയും; പുതിയ ബില്ലുകൾ മാത്രം നിൽക്കും.
- നിങ്ങൾ ഇനി ഇടപാട് നടത്താത്ത ഉപഭോക്താക്കളെയും വിതരണക്കാരെയും ആർക്കൈവ് ചെയ്യുക.

## എന്തെങ്കിലും തെറ്റായി തോന്നുമ്പോൾ

| നിങ്ങൾ ശ്രദ്ധിക്കുന്നത് | ആദ്യം ഇവിടെ നോക്കുക |
|---|---|
| ഉപഭോക്താവ് അടച്ചെന്ന് പറയുന്നു, പക്ഷേ ഇൻവോയ്സ് അടയ്ക്കാത്തതായി കാണിക്കുന്നു | **Payment History** (ഇൻവോയ്സോ റഫറൻസോ തിരയുക) |
| സ്റ്റോക്ക് ഷെൽഫിലുള്ളതിൽ നിന്ന് വ്യത്യസ്തമാണ് | ആ ഉൽപ്പന്നത്തിന്റെ **ഇൻവെന്ററി → Movements**, തുടർന്ന് കാരണം സഹിതം ക്രമീകരിക്കുക |
| വിതരണക്കാരന്റെ ബാക്കി അവർ പറയുന്നതല്ല | വിതരണക്കാരന്റെ പേജ്: ബില്ലുകൾ, പേയ്മെന്റുകൾ, ഡെബിറ്റ് നോട്ടുകൾ; തെറ്റായ ബില്ലിൽ പേയ്മെന്റ് രേഖപ്പെടുത്തിയിട്ടുണ്ടോ എന്ന് നോക്കുക |
| ബില്ലിൽ തുക തെറ്റാണ് | അത് തുറന്ന് **Edit bill** ചെയ്യുക (തുറന്നതും അടയ്ക്കാത്തതുമായിരിക്കുമ്പോൾ മാത്രം) |
| വിൽപ്പന തെറ്റായ വിലയ്ക്ക് പോയി | **Cancel Invoice** ചെയ്ത് വീണ്ടും ബിൽ ചെയ്യുക, അല്ലെങ്കിൽ വ്യത്യാസത്തിന് **ക്രെഡിറ്റ് നോട്ട്** നൽകുക |
| നികുതി തെറ്റായി തോന്നുന്നു | ഉൽപ്പന്നത്തിന്റെ **Tax Rate %**, തുടർന്ന് രേഖയിലെ വരി |
| റിപ്പോർട്ടിലെ ഒരു സംഖ്യ വിചിത്രമായി തോന്നുന്നു | റിപ്പോർട്ട് വരിയിൽ നിന്ന് അതിന് പിന്നിലെ രേഖയിലേക്ക് ക്ലിക്ക് ചെയ്ത് പോകുക |
