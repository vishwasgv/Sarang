# ഗൈഡ്: ഒന്നിലധികം കമ്പ്യൂട്ടറുകളിൽ Sarang ഉപയോഗിക്കൽ

ചില കടകളിൽ രണ്ടോ മൂന്നോ പേർക്ക് ഒരേ സമയം ജോലി ചെയ്യേണ്ടി വരും: ഒരാൾ കൗണ്ടറിൽ, ഒരാൾ വാങ്ങലുകളിൽ, ഒരാൾ കണക്കുകൾ പരിശോധിക്കുന്നു. Sarang-ന് ഇത് നിങ്ങളുടെ സ്വന്തം കടയുടെ നെറ്റ്‌വർക്കിൽ ചെയ്യാൻ കഴിയും. ഇന്റർനെറ്റിലൂടെ ഒന്നും പോകുന്നില്ല.

## ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

- ഒരു കമ്പ്യൂട്ടർ എല്ലാ ഡാറ്റയും സൂക്ഷിക്കുന്നു. അതിനെ **സെർവർ** എന്ന് വിളിക്കുന്നു. കടയുടെ സമയത്ത് അത് ഓൺ ആക്കി Sarang തുറന്നുവയ്ക്കുക.
- മറ്റ് കമ്പ്യൂട്ടറുകൾ **ക്ലയന്റുകൾ** ആണ്. അവയിൽ ബിസിനസ് ഡാറ്റ ഇല്ല. സെർവറിലുള്ള ഡാറ്റ അവ കാണിക്കുകയും മാറ്റുകയും ചെയ്യുന്നു.
- കമ്പ്യൂട്ടറുകൾക്കിടയിൽ പോകുന്നതെല്ലാം നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന **പങ്കിട്ട രഹസ്യ കോഡ്** ഉപയോഗിച്ച് എൻക്രിപ്റ്റ് ചെയ്യപ്പെടുന്നു. നിങ്ങൾ ഓൺ ചെയ്യുന്നതുവരെ ഇത് ഓഫ് ആണ്.

## നിങ്ങൾക്ക് എന്ത് വേണം

- എല്ലാ കമ്പ്യൂട്ടറുകളും കടയുടെ ഒരേ നെറ്റ്‌വർക്കിൽ (ഒരേ Wi-Fi അല്ലെങ്കിൽ ഒരേ കേബിൾ നെറ്റ്‌വർക്ക്).
- മതിയായ **സീറ്റുകൾ** ഉള്ള ലൈസൻസ്. കടയിലെ കമ്പ്യൂട്ടർ ഒരു സീറ്റായി കണക്കാക്കുന്നു, ഒരേ സമയം സൈൻ ഇൻ ചെയ്ത ഓരോ മറ്റ് കമ്പ്യൂട്ടറും ഒരു സീറ്റ് കൂടി ഉപയോഗിക്കുന്നു. സൗജന്യ ട്രയലിൽ രണ്ട് കമ്പ്യൂട്ടറുകൾ അനുവദിക്കുന്നു, അതിനാൽ നിങ്ങൾക്ക് പരീക്ഷിച്ചുനോക്കാം. സീറ്റുകൾ ചേർക്കാൻ ലൈസൻസ് സ്ക്രീനിലെ വിലാസത്തിലേക്ക് എഴുതുക.

## സെർവർ സജ്ജമാക്കുക (ഡാറ്റ സൂക്ഷിക്കുന്ന കമ്പ്യൂട്ടർ)

1. ഉടമയായി സൈൻ ഇൻ ചെയ്യുക. **Settings → Business features → Multi-user** ലേക്ക് പോകുക.
2. **ഈ കമ്പ്യൂട്ടർ ഡാറ്റ സൂക്ഷിക്കുന്നു (സെർവർ)** തിരഞ്ഞെടുക്കുക.
3. കാണിക്കുന്ന **വിലാസം** (ഉദാഹരണത്തിന് 192.168.1.10:47821), **പങ്കിട്ട രഹസ്യ കോഡ്** എന്നിവ കുറിച്ചുവയ്ക്കുക. രഹസ്യ കോഡ് എപ്പോൾ വേണമെങ്കിലും **പുതിയ രഹസ്യ കോഡ് ഉണ്ടാക്കുക** ഉപയോഗിച്ച് മാറ്റാം.
4. **സേവ് ചെയ്ത് Sarang പുനരാരംഭിക്കുക** അമർത്തുക.
5. മറ്റൊരു കമ്പ്യൂട്ടറിന് ബന്ധിപ്പിക്കാൻ കഴിയുന്നില്ലെങ്കിൽ, ഈ കമ്പ്യൂട്ടറിലെ Windows ഫയർവാളിൽ സ്വകാര്യ നെറ്റ്‌വർക്കുകൾക്കായി Sarang-ന് അനുമതി നൽകുക.

## ഓരോ ക്ലയന്റ് കമ്പ്യൂട്ടറും സജ്ജമാക്കുക

1. കമ്പ്യൂട്ടറിൽ Sarang ഇൻസ്റ്റാൾ ചെയ്ത് തുറക്കുക.
2. സൈൻ ഇൻ പേജിൽ **കമ്പ്യൂട്ടർ കണക്ഷൻ ക്രമീകരണങ്ങൾ (ഒന്നിലധികം കമ്പ്യൂട്ടറുകൾ)** അമർത്തുക.
3. **ഈ കമ്പ്യൂട്ടർ മറ്റൊരു കമ്പ്യൂട്ടറുമായി ബന്ധിപ്പിക്കുന്നു (ക്ലയന്റ്)** തിരഞ്ഞെടുക്കുക. സെർവറിന്റെ വിലാസവും പങ്കിട്ട രഹസ്യ കോഡും ടൈപ്പ് ചെയ്ത്, **കണക്ഷൻ പരിശോധിക്കുക** അമർത്തി, തുടർന്ന് **സേവ് ചെയ്ത് Sarang പുനരാരംഭിക്കുക** അമർത്തുക.
4. നിങ്ങളുടെ സ്വന്തം യൂസർനെയിമും പാസ്‌വേഡും ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്യുക. **Settings → Users**-ൽ ഓരോരുത്തർക്കും യൂസർനെയിം ഉണ്ടാക്കുക, അപ്പോൾ ഓരോ വിൽപ്പനയിലും മാറ്റത്തിലും ആരാണ് ചെയ്തതെന്ന് കാണിക്കും.

## ഒരുമിച്ച് പ്രവർത്തിക്കൽ

- ഓരോ വ്യക്തിക്കും സ്വന്തം സൈൻ ഇനും സ്വന്തം അനുമതികളും ഉണ്ട്.
- രണ്ടുപേർ ഒരേ നിമിഷം സേവ് ചെയ്താൽ, ഒരാൾ മറ്റേയാൾക്കായി അൽപ്പം കാത്തിരിക്കും. ഇൻവോയ്സ് നമ്പറുകൾ പോലുള്ളവ ഒരിക്കലും ആവർത്തിക്കില്ല. രണ്ടുപേർ അവസാന യൂണിറ്റ് വിറ്റാൽ, ഒരു വിൽപ്പന മാത്രമേ നടക്കൂ.
- ആരെങ്കിലും ഒരു ഉപഭോക്താവിനെയോ വിതരണക്കാരനെയോ ഉൽപ്പന്നത്തെയോ എഡിറ്റ് ചെയ്യാൻ തുറക്കുമ്പോൾ, അതേ രേഖ തുറക്കുന്ന മറ്റുള്ളവർക്ക് **"… ഇത് മറ്റൊരു കമ്പ്യൂട്ടറിൽ തുറന്നിട്ടുണ്ട്"** എന്ന് കാണിക്കും, അത് അടയ്ക്കുന്നതുവരെ അവർക്ക് സേവ് ചെയ്യാൻ കഴിയില്ല.
- മറ്റൊരു കമ്പ്യൂട്ടർ ഡാറ്റ മാറ്റുമ്പോൾ ഒരു ചെറിയ കുറിപ്പ് വരും: **"… മറ്റൊരു കമ്പ്യൂട്ടറിൽ കുറച്ച് ഡാറ്റ മാറ്റി. പുതുക്കുക."** ഏറ്റവും പുതിയത് കാണാൻ പുതുക്കുക അമർത്തുക.
- സെർവറിലെ **Settings → Business features → Multi-user** ആരൊക്കെ ബന്ധിപ്പിച്ചിരിക്കുന്നു എന്ന് കാണിക്കുകയും ഒരു കമ്പ്യൂട്ടറിനെ വിച്ഛേദിക്കാൻ അനുവദിക്കുകയും ചെയ്യുന്നു.

## സെർവർ കമ്പ്യൂട്ടറിൽ മാത്രം നടക്കുന്നവ

ബാക്കപ്പും പുനഃസ്ഥാപനവും, ഫയലുകൾ ഇറക്കുമതി ചെയ്യൽ, ട്യൂട്ടോറിയൽ, ലൈസൻസ് സജീവമാക്കൽ, ഡിസ്കിൽ നിന്ന് രേഖകൾ തുറക്കൽ, അടുക്കള ടിക്കറ്റ് പ്രിന്റിംഗ് എന്നിവ സെർവർ കമ്പ്യൂട്ടറിൽ നടക്കുന്നു. ക്ലയന്റ് കമ്പ്യൂട്ടർ ഇൻവോയ്സുകൾ സ്വന്തം പ്രിന്ററിൽ പ്രിന്റ് ചെയ്യുകയും റിപ്പോർട്ടുകൾ (Excel, PDF, CSV) സ്വന്തം ഡിസ്കിൽ സേവ് ചെയ്യുകയും ചെയ്യുന്നു.

## നല്ല ശീലങ്ങൾ

- സെർവർ സ്ഥിരമായ വൈദ്യുതിയിൽ സൂക്ഷിക്കുകയും സെർവറിൽ ദിവസവും ബാക്കപ്പ് എടുക്കുകയും ചെയ്യുക. സെർവർ ഓഫ് ആണെങ്കിൽ ക്ലയന്റുകൾക്ക് ജോലി ചെയ്യാൻ കഴിയില്ല.
- ഡാറ്റ ഫയൽ മറ്റ് കമ്പ്യൂട്ടറുകളിലേക്ക് പകർത്തരുത്, ഒരേ ഫയൽ നെറ്റ്‌വർക്ക് വഴി രണ്ട് കമ്പ്യൂട്ടറുകളിൽ നിന്ന് തുറക്കരുത്. പകരം ഈ സവിശേഷത ഉപയോഗിക്കുക. ഒരു ഫയൽ രണ്ട് കമ്പ്യൂട്ടറുകളിൽ നിന്ന് തുറന്നാൽ അത് കേടാകാം.
- പങ്കിട്ട രഹസ്യ കോഡ് സ്വകാര്യമായി സൂക്ഷിക്കുക. ആരെങ്കിലും കട വിട്ടാൽ **പുതിയ രഹസ്യ കോഡ് ഉണ്ടാക്കുക** അമർത്തി പുതിയത് മറ്റ് കമ്പ്യൂട്ടറുകളിൽ ടൈപ്പ് ചെയ്യുക.
