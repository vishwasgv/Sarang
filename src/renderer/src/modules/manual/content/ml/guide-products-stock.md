# ഗൈഡ്: ഉൽപ്പന്നങ്ങൾ, വിഭാഗങ്ങൾ, സ്റ്റോക്ക്

നിങ്ങൾ വിൽക്കുന്നത് എങ്ങനെ സജ്ജീകരിക്കാം, സ്റ്റോക്ക് ശരിയായി സൂക്ഷിക്കുക, ഒരു സംഖ്യ എന്തുകൊണ്ട് അതാണെന്ന് കണ്ടെത്തുക.

## 1. ആദ്യം വിഭാഗങ്ങൾ (2 മിനിറ്റ്, മണിക്കൂറുകൾ ലാഭിക്കും)

ഫിൽട്ടറിംഗിനും റിപ്പോർട്ടുകൾക്കുമായി വിഭാഗങ്ങൾ ഉൽപ്പന്നങ്ങളെ ഗ്രൂപ്പുചെയ്യുന്നു (ഉദാ. *ബൾബുകൾ*, *സ്വിച്ചുകൾ*, *വയർ*).

- **Inventory → ഉൽപ്പന്നങ്ങൾ → വിഭാഗം ബട്ടൺ** **Manage Categories** തുറക്കുന്നു: ചേർക്കുക, പേര് മാറ്റുക, ഒരു ഉപ-വിഭാഗം ചേർക്കുക, അല്ലെങ്കിൽ ആർക്കൈവ് ചെയ്യുക.
- **ഒരു ഉൽപ്പന്നം സൃഷ്ടിക്കുമ്പോൾ വേഗത്തിൽ ചേർക്കൽ**: ഉൽപ്പന്ന ഫോമിൽ, **+ Create new category…** തിരഞ്ഞെടുക്കുക, പേര് ടൈപ്പ് ചെയ്യുക (അത് ഒരു ഉപ-വിഭാഗമാണെങ്കിൽ പാരന്റും) അത് ഉടനടി സൃഷ്ടിക്കപ്പെടുകയും തിരഞ്ഞെടുക്കപ്പെടുകയും ചെയ്യും.

## 2. ഒരു ഉൽപ്പന്നം ചേർക്കുക

**Inventory → ഉൽപ്പന്നങ്ങൾ → Add Product.**

| ഫീൽഡ് | എന്ത് നൽകണം |
|---|---|
| ഉൽപ്പന്നത്തിന്റെ പേര് | നിങ്ങളും നിങ്ങളുടെ ഉപഭോക്താക്കളും അതിനെ എന്താണ് വിളിക്കുന്നത് |
| SKU / ബാർകോഡ് | നിങ്ങളുടെ സ്വന്തം കോഡ്, അല്ലെങ്കിൽ നിർമ്മാതാവിന്റെ ബാർകോഡ് സ്കാൻ ചെയ്യുക |
| HSN കോഡ് | നിങ്ങളുടെ അക്കൗണ്ടന്റ് നൽകുന്ന സാധന വർഗ്ഗീകരണ കോഡ് (സേവനങ്ങൾക്ക് SAC) |
| ഉൽപ്പന്ന തരം | **Standard** (സ്റ്റോക്ക് എണ്ണുന്നു) അല്ലെങ്കിൽ **Service** (സ്റ്റോക്ക് ഇല്ല, ഉദാ. ജോലി) |
| യൂണിറ്റ് | PCS, KG, L, M, BOX തുടങ്ങിയവ |
| വില (ചെലവ്) | ഒരു യൂണിറ്റിന് നിങ്ങൾ അടയ്ക്കുന്നത്, **നികുതിക്ക് മുമ്പ്** (സ്റ്റോക്കിന്റെ വിലയിൽ വാങ്ങൽ നികുതി ഒരിക്കലും ഉൾപ്പെടില്ല) |
| വിൽപ്പന വില | ഒരു യൂണിറ്റിന് നിങ്ങൾ ഈടാക്കുന്നത്. സ്ഥിരസ്ഥിതിയായി നികുതിക്ക് മുമ്പ്; **Prices include tax** ഓണാക്കിയാൽ നികുതി ഉൾപ്പെടെ |
| MRP | അച്ചടിച്ച പരമാവധി വില, ഉണ്ടെങ്കിൽ (നിങ്ങളുടെ വിലയ്ക്ക് അടുത്തായി വെട്ടിയതായി കാണിക്കും) |
| നികുതി നിരക്ക് % | ഈ ഉൽപ്പന്നത്തിനുള്ള GST നിരക്ക്. അത് ടൈപ്പ് ചെയ്യുക, അല്ലെങ്കിൽ **Settings → Tax Configuration** ൽ നിന്ന് ഒരു നിരക്ക് ക്ലിക്ക് ചെയ്യുക |
| റീഓർഡർ ലെവൽ / അളവ് | കുറഞ്ഞ-സ്റ്റോക്ക് അലേർട്ട് ഉയർത്തുന്ന സ്റ്റോക്ക് ലെവൽ, നിങ്ങൾ സാധാരണയായി എത്ര ഓർഡർ ചെയ്യുന്നു |
| ആരംഭ അളവ് | ഉൽപ്പന്നം ചേർക്കുമ്പോൾ നിങ്ങളുടെ പക്കൽ ഇതിനകം ഉള്ള സ്റ്റോക്ക് |

**നിങ്ങൾ വേറെ പറയാത്തിടത്തോളം വിലകൾ നികുതിക്ക് മുമ്പുള്ളതാണ്.** സ്ഥിരസ്ഥിതിയായി വിൽക്കുമ്പോഴോ വാങ്ങുമ്പോഴോ Sarang മുകളിൽ നികുതി ചേർക്കുന്നു: 18 ശതമാനം നികുതിയോടെ 100 വിൽപ്പന വില 118 ന് വിൽക്കുന്നു. നിങ്ങളുടെ ഷെൽഫ് വിലയിൽ ഇതിനകം നികുതി ഉൾപ്പെട്ടിട്ടുണ്ടെങ്കിൽ, **Prices include tax** ഓണാക്കുക (Settings ൽ, അല്ലെങ്കിൽ ഓരോ രേഖയിലും സ്വിച്ച്) Sarang നികുതി പിന്നോട്ട് കണക്കാക്കും, അതിനാൽ നിങ്ങൾ കൈകൊണ്ട് ഹരിക്കേണ്ടതില്ല. *ഗൈഡ്: നികുതിയും GST യും* കാണുക.

നിങ്ങൾ ഇവിടെ സജ്ജമാക്കുന്ന നികുതി നിരക്ക് ഉൽപ്പന്നം തിരഞ്ഞെടുക്കുമ്പോൾ ഇൻവോയ്സുകൾ, ക്വൊട്ടേഷനുകൾ, സെയിൽസ് ഓർഡറുകൾ, പർച്ചേസ് ഓർഡറുകൾ, സപ്ലയർ ബില്ലുകൾ, ഡെബിറ്റ് നോട്ടുകൾ എന്നിവയിൽ സ്വയമേവ പൂരിപ്പിക്കപ്പെടും. ഒരൊറ്റ വരിയിൽ നിങ്ങൾക്ക് ഇപ്പോഴും അത് മാറ്റാം.

വേരിയന്റുകൾ (വലുപ്പവും നിറവും), ഭാരം അടിസ്ഥാനമാക്കിയുള്ള വിൽപ്പന, കാലാവധിയുള്ള ബാച്ചുകൾ, സീരിയൽ അല്ലെങ്കിൽ IMEI നമ്പറുകൾ, കിറ്റുകൾ (ഒന്നായി വിൽക്കുന്ന നിരവധി ഉൽപ്പന്നങ്ങൾ) എന്നിവ നിങ്ങളുടെ ബിസിനസ് തരം അല്ലെങ്കിൽ **Settings → Additional Business Features** ൽ ഓണാക്കുന്നു.

## 3. സ്റ്റോക്ക് അകത്തേക്ക് കൊണ്ടുവരൽ

ഇവയിലൊന്ന് സംഭവിക്കുമ്പോൾ **മാത്രമേ** സ്റ്റോക്ക് കൂടുകയുള്ളൂ:

1. അംഗീകരിച്ച ഒരു പർച്ചേസ് ഓർഡറിൽ **Receive Stock**.
2. ഒരു ഉൽപ്പന്നവുമായി ലിങ്ക് ചെയ്ത വരിയുള്ള **GRN** **പോസ്റ്റ് (Posted)** ചെയ്യപ്പെടുന്നു.
3. ഉൽപ്പന്നം ആദ്യമായി സൃഷ്ടിക്കുമ്പോൾ **ആരംഭ അളവ്**.
4. ഒരു **സ്റ്റോക്ക് ക്രമീകരണം** (താഴെ).
5. ഒരു **സെയിൽസ് റിട്ടേൺ** സാധനങ്ങൾ തിരികെ എടുക്കുന്നു, അല്ലെങ്കിൽ ഒരു **പ്രൊഡക്ഷൻ റൺ** പൂർത്തിയാകുന്നു (നിർമ്മാതാക്കൾ).

ഒരു **സപ്ലയർ ബിൽ** മാത്രം ഒരിക്കലും സ്റ്റോക്ക് ചേർക്കില്ല. *ഗൈഡ്: സപ്ലയർമാരിൽ നിന്ന് വാങ്ങൽ* കാണുക.

## 4. സ്റ്റോക്ക് പുറത്തേക്ക് എടുക്കൽ

Billing ൽ ഒരു വിൽപ്പന സ്ഥിരീകരിക്കുമ്പോൾ (അല്ലെങ്കിൽ ഒരു സെയിൽസ് ഓർഡർ ഇൻവോയ്സ് ചെയ്യുമ്പോൾ), ഒരു **ഡെബിറ്റ് നോട്ട്** സാധനങ്ങൾ തിരികെ അയക്കുമ്പോൾ, സാധനങ്ങൾ ഉൽപ്പാദനത്തിൽ ഉപയോഗിക്കുമ്പോൾ, അല്ലെങ്കിൽ നിങ്ങൾ അത് താഴേക്ക് ക്രമീകരിക്കുമ്പോൾ സ്റ്റോക്ക് കുറയുന്നു.

നിങ്ങളുടെ പക്കൽ ഉള്ളതിലും കൂടുതൽ വിൽക്കാൻ Sarang നിങ്ങളെ അനുവദിക്കില്ല. *Insufficient stock* എന്നതോടെ ഒരു വിൽപ്പന തടയപ്പെട്ടാൽ, ആദ്യം വാങ്ങൽ സ്വീകരിക്കുക അല്ലെങ്കിൽ ഒരു കാരണത്തോടെ സ്റ്റോക്ക് കൗണ്ട് തിരുത്തുക. സാധനങ്ങൾ രേഖപ്പെടുത്തുന്നതിന് മുമ്പ് നിങ്ങൾക്ക് ശരിക്കും വിൽക്കണമെങ്കിൽ, **Settings → Business Features → Stock rules** ൽ നെഗറ്റീവ് സ്റ്റോക്ക് ഓണാക്കുക; സാധനങ്ങൾ സ്വീകരിക്കുന്നത് വരെ അളവ് പൂജ്യത്തിന് താഴെ കാണിക്കും.

## 5. സ്റ്റോക്ക് പരിശോധിച്ച് തിരുത്തുക

- **Inventory** ഓരോ ഉൽപ്പന്നത്തെയും നിലവിലെ അളവ്, റീഓർഡർ ലെവൽ, ശരാശരി വില, സ്റ്റോക്ക് മൂല്യം എന്നിവയോടെ പട്ടികപ്പെടുത്തുന്നു. **Low Stock** ടാബ് എന്താണ് ഓർഡർ ചെയ്യേണ്ടതെന്ന് കാണിക്കുന്നു.
- **സ്റ്റോക്ക് ക്രമീകരിക്കുക**: ഒരു വരിയിലെ ക്രമീകരണ ഐക്കൺ ക്ലിക്ക് ചെയ്ത് **പുതിയ അളവ്** നൽകുക (വ്യത്യാസമല്ല). ഒരു കാരണം നൽകുക (കേടുപാട്, കൗണ്ട്, ആരംഭ ബാലൻസ്). സ്റ്റോക്ക് കൂട്ടുമ്പോൾ ചേർത്ത യൂണിറ്റുകളുടെ വില നിങ്ങൾക്ക് രേഖപ്പെടുത്താം.
- **Movements** (Inventory ലെ ബട്ടൺ) ഓരോ മാറ്റത്തിന്റെയും വായിക്കാൻ-മാത്രമുള്ള ചരിത്രമാണ്: Stock Added, Sale, PO Received, Adjustment, Sale Return, കൂടുതൽ. "ഈ സംഖ്യ എന്തുകൊണ്ട് അതാണ്?" എന്നതിന് ഉത്തരം നൽകാൻ ഇത് ഉപയോഗിക്കുക.
- **സ്റ്റോക്ക് എണ്ണൽ**: **Inventory → Stock Counts → New count**. ഓരോ ഇനത്തിനും നിങ്ങളുടെ പക്കൽ എന്താണെന്ന് കരുതുന്നു എന്നതിന്റെ ഒരു സ്നാപ്ഷോട്ട് Sarang എടുക്കുന്നു; നിങ്ങൾ യഥാർത്ഥത്തിൽ എണ്ണിയത് ടൈപ്പ് ചെയ്യുന്നു, അത് വ്യത്യാസവും അതിന്റെ മൂല്യവും കാണിക്കുന്നു. നിങ്ങൾ **Post** അമർത്തുന്നതുവരെ ഒന്നും മാറില്ല, ഇത് ഓരോ വ്യത്യാസത്തെയും നിങ്ങളുടെ പ്രധാന ലൊക്കേഷനിൽ ഒരു സ്റ്റോക്ക് ക്രമീകരണമായി (കാരണം: സ്റ്റോക്ക് കൗണ്ട്) മാറ്റുന്നു. ഒരു സമയത്ത് ഒരു കൗണ്ട് മാത്രമേ തുറന്നിരിക്കാൻ കഴിയൂ. ബാച്ചുകളോ സീരിയൽ നമ്പറുകളോ കാലാവധിയോ ഉള്ള ഇനങ്ങൾ മൊത്തം അളവ് കൊണ്ട് മാത്രമേ എണ്ണുകയുള്ളൂ. പോസ്റ്റിംഗ് തടസ്സപ്പെട്ടാൽ, കൗണ്ട് തുറന്നിരിക്കും, ഇതിനകം പോസ്റ്റ് ചെയ്ത വരികൾ പോസ്റ്റ് ചെയ്തതായി തന്നെ തുടരും: ബാക്കിയുള്ളവ പൂർത്തിയാക്കാൻ വീണ്ടും Post അമർത്തുക. **Reports → Stock Count Variances** എന്താണ് കുറവോ കൂടുതലോ ആയിരുന്നതെന്ന് കാണിക്കുന്നു.
- **Stock Locations**: കട, ഗോഡൗൺ അല്ലെങ്കിൽ വാൻ എന്നിവയ്ക്കായി പ്രത്യേക സ്റ്റോക്ക് സൂക്ഷിക്കുക, അവയ്ക്കിടയിൽ സ്റ്റോക്ക് നീക്കുക.
- **Bin Locations**: **Inventory → Bin Locations** ഒരു ലൊക്കേഷനിൽ ഓരോ ഇനവും ഏത് ഷെൽഫ്, റാക്ക് അല്ലെങ്കിൽ ബിന്നിലാണ് (ഉദാ. A-3-2) എന്ന് രേഖപ്പെടുത്തുന്നു, ആർക്കും അത് കണ്ടെത്താൻ കഴിയും. ഇത് കൈകൊണ്ട് ടൈപ്പ് ചെയ്ത ഒരു ലേബലാണ്: ഒരു ലൊക്കേഷനിൽ ഒരു ഇനത്തിന് ഒരു ബിൻ, ഇത് ഈ സ്ക്രീനിൽ മാത്രമേ ദൃശ്യമാകൂ (ഇനിയും റിപ്പോർട്ടുകളിലോ അച്ചടിച്ച പട്ടികകളിലോ അല്ല).
- **Stock Journal**: **Inventory → Stock Journal** ആകൃതി മാറുന്ന സാധനങ്ങൾ രേഖപ്പെടുത്തുന്നു, ഒരു കാർട്ടൺ പാക്കുകളായി പൊട്ടിക്കുന്നത് പോലെ: എന്താണ് പുറത്തുപോകുന്നത്, എന്താണ് അകത്ത് വരുന്നത് എന്ന് തിരഞ്ഞെടുത്ത് ഒരുമിച്ച് സേവ് ചെയ്യുക. പുറത്തുപോകുന്ന മൂല്യം അളവ് അനുസരിച്ച് അകത്ത് വരുന്ന ഇനങ്ങളിൽ വിതരണം ചെയ്യപ്പെടുന്നു. സേവ് ചെയ്ത ശേഷം ഇത് എഡിറ്റ് ചെയ്യാനോ പഴയപടിയാക്കാനോ കഴിയില്ല: വിപരീത എൻട്രി ഉപയോഗിച്ച് ഒരു തെറ്റ് തിരുത്തുക.
- **ഓർഡറുകളിൽ വാഗ്ദാനം ചെയ്തത്**: **Inventory** ഉം Stock Summary റിപ്പോർട്ടും ഓരോ ഇനത്തിനും അടുത്തായി, തുറന്ന സെയിൽസ് ഓർഡറുകളിൽ എത്ര വാഗ്ദാനം ചെയ്തിട്ടുണ്ടെന്ന് കാണിക്കുന്നു. ഇത് ഒരു ഓർമ്മപ്പെടുത്തലാണ്, തടയലല്ല: വാഗ്ദാനം ചെയ്ത സ്റ്റോക്ക് വിൽക്കുന്നത് ഒന്നും തടയുന്നില്ല.

## 6. തീരുന്നതിന് മുമ്പ് റീഓർഡർ ചെയ്യുക

- ഓരോ ഉൽപ്പന്നത്തിലും ഒരു **റീഓർഡർ ലെവൽ** സജ്ജമാക്കുക.
- **Dashboard** ലെ കുറഞ്ഞ-സ്റ്റോക്ക് ടൈലുകളും ബെൽ അലേർട്ടുകളും ശ്രദ്ധിക്കുക. ഒരു കുറഞ്ഞ-സ്റ്റോക്ക് അലേർട്ട് ക്ലിക്ക് ചെയ്താൽ **Inventory** തുറക്കും.
- **Inventory** സ്ക്രീനിൽ, **Generate Reorder POs** ഓരോ ഉൽപ്പന്നത്തിന്റെയും സ്ഥിരസ്ഥിതി സപ്ലയറെ ഉപയോഗിച്ച് അതിന്റെ റീഓർഡർ ലെവലിന് താഴെയുള്ള എല്ലാറ്റിനും ഡ്രാഫ്റ്റ് പർച്ചേസ് ഓർഡറുകൾ സൃഷ്ടിക്കുന്നു (ആദ്യം ഉൽപ്പന്നത്തിൽ ഒരു സ്ഥിരസ്ഥിതി സപ്ലയറെ സജ്ജമാക്കുക).

## 7. എന്റെ സ്റ്റോക്കിന് എന്ത് മൂല്യമുണ്ട്?

**Inventory** ഓരോ ഉൽപ്പന്നത്തിന്റെയും മൂല്യം കാണിക്കുന്നു (അളവ് x ശരാശരി വില). **Reports → Stock Summary**, **Stock Ledger** (ആരംഭവും അവസാനവും ഉള്ള ഓരോ ചലനവും), **Inventory Ageing**, ലൊക്കേഷൻ അനുസരിച്ചും ട്രാൻസ്ഫർ റിപ്പോർട്ടുകളും മൂല്യനിർണ്ണയം, ചലനം, ഇനങ്ങൾ എത്രകാലമായി അനങ്ങാതെ കിടക്കുന്നു എന്നിവ കാണിക്കുന്നു. മൂല്യനിർണ്ണയം നിങ്ങൾ ഉപയോഗിക്കുന്ന രീതി പിന്തുടരുന്നു (ശരാശരി, FIFO, ഓണാക്കിയിടത്ത് മറ്റുള്ളവ) ഓരോ റിപ്പോർട്ടും അത് ഇന്നത്തെ തീയതി പ്രകാരമാണെന്ന് പറയുന്നു. ഒരു വാങ്ങലിൽ **ലാൻഡഡ് കോസ്റ്റ്** ആയി നൽകിയ ചരക്കുനീക്ക അല്ലെങ്കിൽ തീരുവ ചെലവുകൾ ആ ഇനങ്ങളുടെ വില ഉയർത്തുന്നു.
