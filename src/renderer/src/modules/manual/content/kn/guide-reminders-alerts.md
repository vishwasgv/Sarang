# ಮಾರ್ಗದರ್ಶಿ: ಜ್ಞಾಪನೆಗಳು ಮತ್ತು ಎಚ್ಚರಿಕೆಗಳು

Sarang ನಿಮಗೆ ಎರಡು ವಿಭಿನ್ನ ವಿಷಯಗಳನ್ನು, ಎರಡು ವಿಭಿನ್ನ ಸ್ಥಳಗಳಲ್ಲಿ ಹೇಳುತ್ತದೆ. ಯಾವುದು ಯಾವುದು ಎಂದು ತಿಳಿಯುವುದು ಹೆಚ್ಚಿನ ಗೊಂದಲವನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ.

|---|---|---|

## ಎಚ್ಚರಿಕೆಗಳು (ಬೆಲ್)

ಏನಾದರೂ ನಿಮ್ಮ ಗಮನ ಬೇಕಾದಾಗ ಬೆಲ್ ಒಂದು ಸಂಖ್ಯೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಅದನ್ನು ತೆರೆಯಿರಿ ಮತ್ತು ಎಚ್ಚರಿಕೆಯನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ:

- **WhatsApp Reminders Due** WhatsApp Reminders ಪರದೆಯನ್ನು ತೆರೆಯುತ್ತದೆ.
- **Low Stock Alert** Inventory ತೆರೆಯುತ್ತದೆ.
- **Auto-Backup Complete** ಮತ್ತು **Database Integrity Issue** Backup ತೆರೆಯುತ್ತವೆ.
- **Compliance Tasks Generated** (CA ಮತ್ತು CS ಸಂಸ್ಥೆಗಳು) Compliance ತೆರೆಯುತ್ತದೆ.

**Open →** ಎಂದು ಗುರುತಿಸಲಾದ ಎಚ್ಚರಿಕೆ ಕ್ಲಿಕ್ ಮಾಡಬಹುದಾದದ್ದು. ಕ್ಲಿಕ್ ಮಾಡುವುದು ಅದನ್ನು ಓದಿದ್ದಾಗಿಯೂ ಗುರುತಿಸುತ್ತದೆ. **Mark all read** ಸಂಖ್ಯೆಯನ್ನು ಅಳಿಸುತ್ತದೆ.

## WhatsApp ಜ್ಞಾಪನೆಗಳು

ನಿಮ್ಮ ವ್ಯಾಪಾರದಲ್ಲಿ ಏನಾಗುತ್ತದೆ ಎಂಬುದರಿಂದ Sarang ಜ್ಞಾಪನೆಗಳನ್ನು ಸಿದ್ಧಪಡಿಸುತ್ತದೆ ಮತ್ತು ಅವುಗಳನ್ನು **WhatsApp Reminders** ನಲ್ಲಿ, ಮೂರು ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ: **Pending**, **Sent** ಮತ್ತು **All**.

ಪ್ರತಿ ಬಾಕಿ ಜ್ಞಾಪನೆಗೆ ಅದು ಯಾರಿಗಾಗಿ, ಸಂದೇಶ, ಮತ್ತು ಅದು ಯಾವಾಗ ಬಾಕಿಯಾಯಿತು ಎಂದು ನೀವು ನೋಡುತ್ತೀರಿ.

೧. **Send on WhatsApp** ಕ್ಲಿಕ್ ಮಾಡಿ. ವ್ಯಕ್ತಿಯ ಸಂಖ್ಯೆ ಮತ್ತು ಈಗಾಗಲೇ ಟೈಪ್ ಮಾಡಿದ ಸಂದೇಶದೊಂದಿಗೆ WhatsApp (ಡೆಸ್ಕ್‌ಟಾಪ್ ಅಪ್ಲಿಕೇಶನ್ ಅಥವಾ WhatsApp Web) ತೆರೆಯುತ್ತದೆ.
೨. WhatsApp ನಲ್ಲಿ **Send** ಒತ್ತಿ. ಈ ಹಂತ ಯಾವಾಗಲೂ ನಿಮ್ಮದೇ.
೩. Sarang ಗೆ ಹಿಂತಿರುಗಿ, ಅದು *Sent* ಗೆ ಹೋಗಲು ಟಿಕ್ (**Mark as sent**) ಕ್ಲಿಕ್ ಮಾಡಿ. ಕಳುಹಿಸದಿರಲು ನೀವು ನಿರ್ಧರಿಸುವ ಒಂದಕ್ಕೆ ಕ್ರಾಸ್ (**Dismiss**) ಬಳಸಿ.

**ಫೋನ್ ಸಂಖ್ಯೆ ಇಲ್ಲದ** ಜ್ಞಾಪನೆ "No phone number, so this can't be sent" ತೋರಿಸುತ್ತದೆ. ಗ್ರಾಹಕ ಅಥವಾ ಪೂರೈಕೆದಾರರಿಗೆ ಸಂಖ್ಯೆ ಸೇರಿಸಿ, ಅಥವಾ ಅದನ್ನು ವಜಾಗೊಳಿಸಿ. ನಿಜವಾಗಿಯೂ ಕಳುಹಿಸಬಹುದಾದ ಜ್ಞಾಪನೆಗಳನ್ನು ಮಾತ್ರ ಕಳುಹಿಸಿದಂತೆ ಗುರುತಿಸಬಹುದು. ನಿಜವಾಗಿರಲು ತುಂಬಾ ಚಿಕ್ಕದಾದ ಫೋನ್ ಸಂಖ್ಯೆ ಇರುವ ಜ್ಞಾಪನೆಯನ್ನು **Failed** ಎಂದು ಗುರುತಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಕಳುಹಿಸಲು ಸಿದ್ಧವೆಂದು ಎಣಿಸಲಾಗುವುದಿಲ್ಲ: ಗ್ರಾಹಕರ ಮೇಲೆ ಸಂಖ್ಯೆಯನ್ನು ಸರಿಪಡಿಸಿ ಮತ್ತು ಮುಂದಿನ ಜ್ಞಾಪನೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

**ಸಂದೇಶ ಕಳುಹಿಸಬಾರದೆಂದು ಕೇಳಿದ ಗ್ರಾಹಕ.** ಗ್ರಾಹಕರ ಫಾರ್ಮ್‌ನಲ್ಲಿ **Do not send this customer messages** ಟಿಕ್ ಮಾಡಿ. ಅವರ ಬಾಕಿ ಜ್ಞಾಪನೆಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ, ಅವು ಇನ್ನು ಮುಂದೆ ಕಳುಹಿಸಲು ಸಿದ್ಧವೆಂದು ಕಾಣಿಸುವುದಿಲ್ಲ, ಮತ್ತು ಒಂದು-ಬಾರಿಯ **Send WhatsApp Message** ಬಟನ್ ಅವುಗಳನ್ನು ನಿರಾಕರಿಸುತ್ತದೆ.

### ಜ್ಞಾಪನೆಗಳನ್ನು ಏನು ಸೃಷ್ಟಿಸುತ್ತದೆ

- **ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳು** (ಕ್ಲಿನಿಕ್‌ಗಳು, ಸಲೂನ್‌ಗಳು, ಜಿಮ್‌ಗಳು ಮತ್ತು ಇತರ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್-ಆಧಾರಿತ ವ್ಯಾಪಾರಗಳು): ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್ ಸಮಯದ **೨೪ ಗಂಟೆ ಮೊದಲು** ಒಂದು ಜ್ಞಾಪನೆ ಮತ್ತು **೨ ಗಂಟೆ ಮೊದಲು** ಇನ್ನೊಂದು. ಅವುಗಳನ್ನು ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ನ ದಿನಾಂಕ ಮತ್ತು ಸಮಯದಿಂದ ಎಣಿಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ನಾಳೆ ೧೦:೦೦ ಕ್ಕೆ ಇರುವ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್ ಇಂದು ೧೦:೦೦ ಮತ್ತು ನಾಳೆ ೦೮:೦೦ ಕ್ಕೆ ಜ್ಞಾಪಿಸಲಾಗುತ್ತದೆ. ೨೪ ಗಂಟೆಗಿಂತ ಕಡಿಮೆ ಮೊದಲು ಮಾಡಿದ ಬುಕಿಂಗ್ ಕೇವಲ ೨-ಗಂಟೆಯ ಜ್ಞಾಪನೆಯನ್ನು ಪಡೆಯುತ್ತದೆ; ೨ ಗಂಟೆಗಿಂತ ಕಡಿಮೆ ಮೊದಲು ಮಾಡಿದ್ದು ಯಾವುದನ್ನೂ ಪಡೆಯುವುದಿಲ್ಲ.
- ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್ ಅನ್ನು **ಮರುಶೆಡ್ಯೂಲ್ ಅಥವಾ ರದ್ದುಗೊಳಿಸುವುದು** ಅದರ ಬಾಕಿ ಜ್ಞಾಪನೆಗಳನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ ಅಥವಾ ತೆಗೆದುಹಾಕುತ್ತದೆ, ಆದ್ದರಿಂದ ಯಾರಿಗೂ ಹಳೆಯ ಸಮಯದ ಬಗ್ಗೆ ಜ್ಞಾಪಿಸಲಾಗುವುದಿಲ್ಲ. ಪೂರ್ಣಗೊಂಡ, ಹಾಜರಾಗದ ಮತ್ತು ಪ್ರಗತಿಯಲ್ಲಿರುವ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳೂ ತಮ್ಮ ಬಾಕಿ ಜ್ಞಾಪನೆಗಳನ್ನು ಕಳೆದುಕೊಳ್ಳುತ್ತವೆ.
- **ಗ್ರಾಹಕರ ಮೇಲೆ ಫೋನ್ ಇಲ್ಲ**: ಯಾವುದೇ ಜ್ಞಾಪನೆ ಸೃಷ್ಟಿಯಾಗುವುದಿಲ್ಲ, ಮತ್ತು ಬುಕ್ ಮಾಡುವಾಗ Sarang ನಿಮಗೆ ಹೇಳುತ್ತದೆ.
- **ಬಾಕಿ ಪಾವತಿಗಳು** (೭, ೧೪ ಮತ್ತು ೩೦ ದಿನಗಳು), **ಸದಸ್ಯತ್ವ ಮತ್ತು ಒಪ್ಪಂದ ನವೀಕರಣಗಳು**, **ಲಸಿಕೆ ಮತ್ತು ಮರುಪರಿಶೀಲನೆ ದಿನಾಂಕಗಳು**, **ಬಾಕಿ ಶುಲ್ಕಗಳು**, **ಕಾನೂನು ವಿಚಾರಣೆ ದಿನಾಂಕಗಳು**, **ಕಳುಹಿಸಿದ ಅಥವಾ ವಿಳಂಬವಾದ ಶಿಪ್ಮೆಂಟ್‌ಗಳು**, **ಸ್ವೀಕರಿಸಿದ ಸರಕುಗಳು** (ಪೂರೈಕೆದಾರರಿಗೆ ಧನ್ಯವಾದ, ಅವರ ಬಳಿ ಫೋನ್ ಸಂಖ್ಯೆ ಇದ್ದರೆ ಮಾತ್ರ), ಮತ್ತು ನಿಮ್ಮ ವ್ಯಾಪಾರಕ್ಕೆ ನಿರ್ದಿಷ್ಟವಾದ ಇನ್ನೂ ಹಲವು.
- **ಗ್ರಾಹಕ ಪುಟ → Send WhatsApp Message**: ನೀವೇ ಬರೆಯುವ ಒಂದು-ಬಾರಿ ಸಂದೇಶ.

### ಒಂದೇ ಬಾರಿಗೆ ಬಹಳಷ್ಟು ಕಳುಹಿಸುವುದು

ದಿನವಿಡೀ ಜ್ಞಾಪನೆಗಳು ಬಾಕಿಯಾಗುತ್ತವೆ. ಅದು ತೆರೆದಿರುವಾಗ Sarang ಪ್ರತಿ ಗಂಟೆಗೆ ಪರಿಶೀಲಿಸುತ್ತದೆ ಮತ್ತು ಬೆಲ್‌ನಲ್ಲಿ **WhatsApp Reminders Due** ಎಚ್ಚರಿಕೆಯನ್ನು ಹಾಕುತ್ತದೆ. Sarang ಮುಚ್ಚಿದ್ದರೆ, ಜ್ಞಾಪನೆಗಳು ಕಾಯುತ್ತವೆ; ಅವು ಕಳೆದುಹೋಗುವುದಿಲ್ಲ, ನೀವು ಮುಂದಿನ ಬಾರಿ ತೆರೆದಾಗ ಬಾಕಿಯೆಂದು ತೋರಿಸುತ್ತವೆ.

### ಸಂದೇಶ ಟೆಂಪ್ಲೇಟ್‌ಗಳು

**Reminders & Messages → Message Templates** ಪ್ರತಿ ಜ್ಞಾಪನೆಯ ಪದಗಳನ್ನು ಬದಲಾಯಿಸಲು, ಲೈವ್ ಮುನ್ನೋಟ ನೋಡಲು, ಮತ್ತು **ಜ್ಞಾಪನೆ ಭಾಷೆ** ಆಯ್ಕೆಮಾಡಲು ನಿಮಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ.

- `{{name}}` ಮತ್ತು `{{date}}` ನಂತಹ ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್‌ಗಳನ್ನು ಬರೆದಂತೆಯೇ ನಿಖರವಾಗಿ ಇರಿಸಿ; Sarang ಅವುಗಳನ್ನು ತುಂಬುತ್ತದೆ. ಆ ಸಂದೇಶ ತುಂಬಲಾಗದ ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್ (`{{nmae}}` ನಂತಹ ಟೈಪಿಂಗ್ ತಪ್ಪು) ಅಥವಾ ಹೊಂದಿಕೆಯಾಗದ ಆವರಣಗಳನ್ನು ನೀವು ಟೈಪ್ ಮಾಡಿದರೆ, ನೀವು ಟೈಪ್ ಮಾಡುವಾಗ Sarang ಎಚ್ಚರಿಸುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಉಳಿಸುವುದಿಲ್ಲ.
- **ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಜ್ಞಾಪನೆ ಭಾಷೆಗಾಗಿ ಪದಗಳನ್ನು ಉಳಿಸಲಾಗುತ್ತದೆ.** ಮೇಲೆ ಹಿಂದಿ ಆಯ್ಕೆಮಾಡಿ ಮತ್ತು ನಿಮ್ಮ ಹಿಂದಿ ಪದಗಳನ್ನು ಬರೆಯಿರಿ; ಇಂಗ್ಲಿಷ್ ಆಯ್ಕೆಮಾಡಿ ಮತ್ತು ನಿಮ್ಮ ಇಂಗ್ಲಿಷ್ ಪದಗಳನ್ನು ಬರೆಯಿರಿ. ಇಂಗ್ಲಿಷ್ ಆಯ್ಕೆಮಾಡಿದಾಗ ಉಳಿಸಿದ ಪದಗಳು ನೀವು ನಿಮ್ಮದೇ ಆದದ್ದನ್ನು ಬರೆಯದ ಯಾವುದೇ ಭಾಷೆಗೂ ಅನ್ವಯಿಸುತ್ತವೆ. **Reset** ಈಗ ಜಾರಿಯಲ್ಲಿರುವ ಪದಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ ಮತ್ತು ಅಂತರ್ನಿರ್ಮಿತ ಪಠ್ಯವನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
