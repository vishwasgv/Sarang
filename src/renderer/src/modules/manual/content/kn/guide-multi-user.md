# ಮಾರ್ಗದರ್ಶಿ: ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ Sarang ಬಳಸುವುದು

ಕೆಲವು ಅಂಗಡಿಗಳಲ್ಲಿ ಇಬ್ಬರು-ಮೂವರು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಕೆಲಸ ಮಾಡಬೇಕಾಗುತ್ತದೆ: ಒಬ್ಬರು ಕೌಂಟರ್‌ನಲ್ಲಿ, ಒಬ್ಬರು ಖರೀದಿ ನೋಡಿಕೊಳ್ಳುತ್ತಾರೆ, ಒಬ್ಬರು ಲೆಕ್ಕ ಪರಿಶೀಲಿಸುತ್ತಾರೆ. Sarang ಇದನ್ನು ನಿಮ್ಮ ಸ್ವಂತ ಅಂಗಡಿಯ ನೆಟ್‌ವರ್ಕ್‌ನಲ್ಲಿ ಮಾಡಬಲ್ಲದು. ಇಂಟರ್ನೆಟ್ ಮೂಲಕ ಏನೂ ಹೋಗುವುದಿಲ್ಲ.

## ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

- ಒಂದು ಕಂಪ್ಯೂಟರ್ ಎಲ್ಲಾ ಡೇಟಾ ಇಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ಅದನ್ನು **ಸರ್ವರ್** ಎನ್ನುತ್ತಾರೆ. ಅಂಗಡಿಯ ಸಮಯದಲ್ಲಿ ಅದನ್ನು ಆನ್ ಇಡಿ ಮತ್ತು Sarang ತೆರೆದಿಡಿ.
- ಉಳಿದ ಕಂಪ್ಯೂಟರ್‌ಗಳು **ಕ್ಲೈಂಟ್‌ಗಳು**. ಅವುಗಳಲ್ಲಿ ವ್ಯವಹಾರದ ಡೇಟಾ ಇರುವುದಿಲ್ಲ. ಸರ್ವರ್‌ನಲ್ಲಿರುವ ಡೇಟಾವನ್ನು ಅವು ತೋರಿಸುತ್ತವೆ ಮತ್ತು ಬದಲಾಯಿಸುತ್ತವೆ.
- ಕಂಪ್ಯೂಟರ್‌ಗಳ ನಡುವೆ ಹೋಗುವ ಎಲ್ಲವೂ ನೀವು ಆಯ್ಕೆ ಮಾಡುವ **ಹಂಚಿಕೆಯ ರಹಸ್ಯ ಕೋಡ್**ನಿಂದ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆಗುತ್ತದೆ. ನೀವು ಆನ್ ಮಾಡುವವರೆಗೆ ಇದು ಆಫ್ ಆಗಿರುತ್ತದೆ.

## ನಿಮಗೆ ಏನು ಬೇಕು

- ಎಲ್ಲಾ ಕಂಪ್ಯೂಟರ್‌ಗಳು ಅಂಗಡಿಯ ಒಂದೇ ನೆಟ್‌ವರ್ಕ್‌ನಲ್ಲಿ (ಒಂದೇ Wi-Fi ಅಥವಾ ಒಂದೇ ಕೇಬಲ್ ನೆಟ್‌ವರ್ಕ್).
- ಸಾಕಷ್ಟು **ಸೀಟುಗಳಿರುವ** ಪರವಾನಗಿ. ಅಂಗಡಿಯ ಕಂಪ್ಯೂಟರ್ ಒಂದು ಸೀಟು ಎಂದು ಎಣಿಕೆಯಾಗುತ್ತದೆ, ಮತ್ತು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಸೈನ್ ಇನ್ ಆದ ಪ್ರತಿ ಇತರ ಕಂಪ್ಯೂಟರ್ ಇನ್ನೊಂದು ಸೀಟನ್ನು ಬಳಸುತ್ತದೆ. ಉಚಿತ ಟ್ರಯಲ್‌ನಲ್ಲಿ ಎರಡು ಕಂಪ್ಯೂಟರ್‌ಗಳಿಗೆ ಅವಕಾಶವಿದೆ, ಆದ್ದರಿಂದ ನೀವು ಪ್ರಯತ್ನಿಸಬಹುದು. ಸೀಟುಗಳನ್ನು ಸೇರಿಸಲು ಪರವಾನಗಿ ಪರದೆಯಲ್ಲಿರುವ ವಿಳಾಸಕ್ಕೆ ಬರೆಯಿರಿ.

## ಸರ್ವರ್ ಸೆಟ್ ಮಾಡಿ (ಡೇಟಾ ಇಡುವ ಕಂಪ್ಯೂಟರ್)

1. ಮಾಲೀಕರಾಗಿ ಸೈನ್ ಇನ್ ಮಾಡಿ. **Settings → Business features → Multi-user** ಗೆ ಹೋಗಿ.
2. **ಈ ಕಂಪ್ಯೂಟರ್ ಡೇಟಾ ಇಟ್ಟುಕೊಳ್ಳುತ್ತದೆ (ಸರ್ವರ್)** ಆಯ್ಕೆ ಮಾಡಿ.
3. ತೋರಿಸಿದ **ವಿಳಾಸ** (ಉದಾಹರಣೆಗೆ 192.168.1.10:47821) ಮತ್ತು **ಹಂಚಿಕೆಯ ರಹಸ್ಯ ಕೋಡ್** ಬರೆದುಕೊಳ್ಳಿ. ರಹಸ್ಯ ಕೋಡ್ ಅನ್ನು ಯಾವಾಗ ಬೇಕಾದರೂ **ಹೊಸ ರಹಸ್ಯ ಕೋಡ್ ರಚಿಸಿ** ಮೂಲಕ ಬದಲಾಯಿಸಬಹುದು.
4. **ಉಳಿಸಿ ಮತ್ತು Sarang ಮರುಪ್ರಾರಂಭಿಸಿ** ಒತ್ತಿ.
5. ಇನ್ನೊಂದು ಕಂಪ್ಯೂಟರ್ ಸಂಪರ್ಕಿಸಲಾಗದಿದ್ದರೆ, ಈ ಕಂಪ್ಯೂಟರ್‌ನ Windows ಫೈರ್‌ವಾಲ್‌ನಲ್ಲಿ ಖಾಸಗಿ ನೆಟ್‌ವರ್ಕ್‌ಗಳಿಗೆ Sarang ಗೆ ಅನುಮತಿ ನೀಡಿ.

## ಪ್ರತಿ ಕ್ಲೈಂಟ್ ಕಂಪ್ಯೂಟರ್ ಸೆಟ್ ಮಾಡಿ

1. ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ Sarang ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ತೆರೆಯಿರಿ.
2. ಸೈನ್ ಇನ್ ಪುಟದಲ್ಲಿ **ಕಂಪ್ಯೂಟರ್ ಸಂಪರ್ಕ ಸೆಟ್ಟಿಂಗ್‌ಗಳು (ಹಲವು ಕಂಪ್ಯೂಟರ್‌ಗಳು)** ಒತ್ತಿ.
3. **ಈ ಕಂಪ್ಯೂಟರ್ ಇನ್ನೊಂದು ಕಂಪ್ಯೂಟರ್‌ಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ (ಕ್ಲೈಂಟ್)** ಆಯ್ಕೆ ಮಾಡಿ. ಸರ್ವರ್‌ನ ವಿಳಾಸ ಮತ್ತು ಹಂಚಿಕೆಯ ರಹಸ್ಯ ಕೋಡ್ ಟೈಪ್ ಮಾಡಿ, **ಸಂಪರ್ಕ ಪರೀಕ್ಷಿಸಿ** ಒತ್ತಿ, ನಂತರ **ಉಳಿಸಿ ಮತ್ತು Sarang ಮರುಪ್ರಾರಂಭಿಸಿ**.
4. ನಿಮ್ಮದೇ ಬಳಕೆದಾರ ಹೆಸರು ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್‌ನಿಂದ ಸೈನ್ ಇನ್ ಮಾಡಿ. **Settings → Users** ನಲ್ಲಿ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ ಬಳಕೆದಾರ ಹೆಸರು ರಚಿಸಿ, ಹೀಗಾಗಿ ಪ್ರತಿ ಮಾರಾಟ ಮತ್ತು ಬದಲಾವಣೆ ಯಾರು ಮಾಡಿದರು ಎಂದು ತೋರಿಸುತ್ತದೆ.

## ಒಟ್ಟಿಗೆ ಕೆಲಸ ಮಾಡುವುದು

- ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ತಮ್ಮದೇ ಸೈನ್ ಇನ್ ಮತ್ತು ತಮ್ಮದೇ ಅನುಮತಿಗಳಿರುತ್ತವೆ.
- ಇಬ್ಬರು ಒಂದೇ ಕ್ಷಣದಲ್ಲಿ ಉಳಿಸಿದರೆ, ಒಬ್ಬರು ಇನ್ನೊಬ್ಬರಿಗಾಗಿ ಸ್ವಲ್ಪ ಕಾಯುತ್ತಾರೆ. ಇನ್‌ವಾಯ್ಸ್ ಸಂಖ್ಯೆಗಳಂತಹ ಸಂಖ್ಯೆಗಳು ಎಂದೂ ಪುನರಾವರ್ತನೆಯಾಗುವುದಿಲ್ಲ. ಇಬ್ಬರು ಕೊನೆಯ ಯೂನಿಟ್ ಮಾರಿದರೆ, ಒಂದೇ ಮಾರಾಟ ಪೂರ್ಣಗೊಳ್ಳುತ್ತದೆ.
- ಯಾರಾದರೂ ಗ್ರಾಹಕ, ಪೂರೈಕೆದಾರ ಅಥವಾ ಉತ್ಪನ್ನವನ್ನು ಸಂಪಾದಿಸಲು ತೆರೆದಾಗ, ಅದೇ ದಾಖಲೆ ತೆರೆಯುವ ಇತರರಿಗೆ **"… ಅವರು ಇದನ್ನು ಇನ್ನೊಂದು ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ತೆರೆದಿದ್ದಾರೆ"** ಕಾಣಿಸುತ್ತದೆ ಮತ್ತು ಅದು ಮುಚ್ಚುವವರೆಗೆ ಅವರು ಉಳಿಸಲಾಗುವುದಿಲ್ಲ.
- ಇನ್ನೊಂದು ಕಂಪ್ಯೂಟರ್ ಡೇಟಾ ಬದಲಾಯಿಸಿದಾಗ ಒಂದು ಸಣ್ಣ ಟಿಪ್ಪಣಿ ಬರುತ್ತದೆ: **"… ಅವರು ಇನ್ನೊಂದು ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಕೆಲವು ಡೇಟಾ ಬದಲಾಯಿಸಿದ್ದಾರೆ. ರಿಫ್ರೆಶ್ ಮಾಡಿ."** ಇತ್ತೀಚಿನದನ್ನು ನೋಡಲು ರಿಫ್ರೆಶ್ ಒತ್ತಿ.
- ಸರ್ವರ್‌ನಲ್ಲಿರುವ **Settings → Business features → Multi-user** ಯಾರು ಸಂಪರ್ಕದಲ್ಲಿದ್ದಾರೆ ಎಂದು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಒಂದು ಕಂಪ್ಯೂಟರ್‌ನ ಸಂಪರ್ಕ ಕಡಿಯಲು ಬಿಡುತ್ತದೆ.

## ಸರ್ವರ್ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ನಡೆಯುವುದು

ಬ್ಯಾಕಪ್ ಮತ್ತು ಮರುಸ್ಥಾಪನೆ, ಫೈಲ್‌ಗಳ ಆಮದು, ಟ್ಯುಟೋರಿಯಲ್, ಪರವಾನಗಿ ಸಕ್ರಿಯಗೊಳಿಸುವುದು, ಡಿಸ್ಕ್‌ನಿಂದ ದಾಖಲೆ ತೆರೆಯುವುದು ಮತ್ತು ಅಡುಗೆಮನೆ ಚೀಟಿ ಮುದ್ರಣ ಸರ್ವರ್ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ನಡೆಯುತ್ತದೆ. ಕ್ಲೈಂಟ್ ಕಂಪ್ಯೂಟರ್ ಇನ್‌ವಾಯ್ಸ್‌ಗಳನ್ನು ತನ್ನದೇ ಪ್ರಿಂಟರ್‌ನಲ್ಲಿ ಮುದ್ರಿಸುತ್ತದೆ ಮತ್ತು ವರದಿಗಳನ್ನು (Excel, PDF, CSV) ತನ್ನದೇ ಡಿಸ್ಕ್‌ನಲ್ಲಿ ಉಳಿಸುತ್ತದೆ.

## ಒಳ್ಳೆಯ ಅಭ್ಯಾಸಗಳು

- ಸರ್ವರ್ ಅನ್ನು ಸ್ಥಿರ ವಿದ್ಯುತ್ತಿನಲ್ಲಿ ಇಡಿ ಮತ್ತು ಸರ್ವರ್‌ನಲ್ಲಿ ಪ್ರತಿದಿನ ಬ್ಯಾಕಪ್ ತೆಗೆದುಕೊಳ್ಳಿ. ಸರ್ವರ್ ಆಫ್ ಆಗಿದ್ದರೆ ಕ್ಲೈಂಟ್‌ಗಳು ಕೆಲಸ ಮಾಡಲಾಗುವುದಿಲ್ಲ.
- ಡೇಟಾ ಫೈಲ್ ಅನ್ನು ಇತರ ಕಂಪ್ಯೂಟರ್‌ಗಳಿಗೆ ನಕಲಿಸಬೇಡಿ ಮತ್ತು ಒಂದೇ ಫೈಲ್ ಅನ್ನು ನೆಟ್‌ವರ್ಕ್ ಮೂಲಕ ಎರಡು ಕಂಪ್ಯೂಟರ್‌ಗಳಿಂದ ತೆರೆಯಬೇಡಿ. ಬದಲಿಗೆ ಈ ವೈಶಿಷ್ಟ್ಯ ಬಳಸಿ. ಒಂದು ಫೈಲ್ ಅನ್ನು ಎರಡು ಕಂಪ್ಯೂಟರ್‌ಗಳಿಂದ ತೆರೆದರೆ ಅದು ಹಾಳಾಗಬಹುದು.
- ಹಂಚಿಕೆಯ ರಹಸ್ಯ ಕೋಡ್ ಖಾಸಗಿಯಾಗಿ ಇಡಿ. ಯಾರಾದರೂ ಅಂಗಡಿ ಬಿಟ್ಟರೆ, **ಹೊಸ ರಹಸ್ಯ ಕೋಡ್ ರಚಿಸಿ** ಒತ್ತಿ ಮತ್ತು ಹೊಸದನ್ನು ಇತರ ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಟೈಪ್ ಮಾಡಿ.
