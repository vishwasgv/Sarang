# ಮಾರ್ಗದರ್ಶಿ: ಉತ್ಪನ್ನಗಳು, ವರ್ಗಗಳು ಮತ್ತು ಸ್ಟಾಕ್

ನೀವು ಮಾರಾಟ ಮಾಡುವುದನ್ನು ಹೇಗೆ ಹೊಂದಿಸುವುದು, ಸ್ಟಾಕ್ ಸರಿಯಾಗಿಡುವುದು, ಮತ್ತು ಒಂದು ಸಂಖ್ಯೆ ಏಕೆ ಹಾಗಿದೆ ಎಂದು ಕಂಡುಹಿಡಿಯುವುದು.

## ೧. ಮೊದಲು ವರ್ಗಗಳು (೨ ನಿಮಿಷ, ಗಂಟೆಗಟ್ಟಲೆ ಉಳಿಸುತ್ತದೆ)

ವರ್ಗಗಳು ಫಿಲ್ಟರಿಂಗ್ ಮತ್ತು ವರದಿಗಳಿಗಾಗಿ ಉತ್ಪನ್ನಗಳನ್ನು ಗುಂಪುಗೂಡಿಸುತ್ತವೆ (ಉದಾ. *ಬಲ್ಬ್‌ಗಳು*, *ಸ್ವಿಚ್‌ಗಳು*, *ವೈರ್*).

- **Inventory → ಉತ್ಪನ್ನಗಳು → ವರ್ಗ ಬಟನ್** **Manage Categories** ತೆರೆಯುತ್ತದೆ: ಸೇರಿಸಿ, ಹೆಸರು ಬದಲಿಸಿ, ಉಪ-ವರ್ಗ ಸೇರಿಸಿ, ಅಥವಾ ಆರ್ಕೈವ್ ಮಾಡಿ.
- **ಉತ್ಪನ್ನ ರಚಿಸುವಾಗ ತ್ವರಿತ-ಸೇರ್ಪಡೆ**: ಉತ್ಪನ್ನ ಫಾರ್ಮ್‌ನಲ್ಲಿ, **+ Create new category…** ಆಯ್ಕೆಮಾಡಿ, ಹೆಸರನ್ನು ಟೈಪ್ ಮಾಡಿ (ಮತ್ತು ಅದು ಉಪ-ವರ್ಗವಾಗಿದ್ದರೆ ಮೂಲ) ಮತ್ತು ಅದು ತಕ್ಷಣ ರಚಿಸಿ ಆಯ್ಕೆಯಾಗುತ್ತದೆ.

## ೨. ಉತ್ಪನ್ನ ಸೇರಿಸಿ

**Inventory → ಉತ್ಪನ್ನಗಳು → Add Product.**

| ಕ್ಷೇತ್ರ | ಏನು ನಮೂದಿಸಬೇಕು |
|---|---|
| ಉತ್ಪನ್ನದ ಹೆಸರು | ನೀವು ಮತ್ತು ನಿಮ್ಮ ಗ್ರಾಹಕರು ಅದನ್ನು ಏನೆಂದು ಕರೆಯುತ್ತಾರೆ |
| SKU / ಬಾರ್‌ಕೋಡ್ | ನಿಮ್ಮ ಸ್ವಂತ ಕೋಡ್, ಅಥವಾ ತಯಾರಕರ ಬಾರ್‌ಕೋಡ್ ಸ್ಕ್ಯಾನ್ ಮಾಡಿ |
| HSN ಕೋಡ್ | ನಿಮ್ಮ ಅಕೌಂಟೆಂಟ್ ನೀಡುವ ಸರಕುಗಳ ವರ್ಗೀಕರಣ ಕೋಡ್ (ಸೇವೆಗಳಿಗೆ SAC) |
| ಉತ್ಪನ್ನ ಪ್ರಕಾರ | **Standard** (ಸ್ಟಾಕ್ ಎಣಿಸಲಾಗುತ್ತದೆ) ಅಥವಾ **Service** (ಸ್ಟಾಕ್ ಇಲ್ಲ, ಉದಾ. ಕೂಲಿ) |
| ಘಟಕ | PCS, KG, L, M, BOX ಇತ್ಯಾದಿ |
| ವೆಚ್ಚ ಬೆಲೆ | ಪ್ರತಿ ಘಟಕಕ್ಕೆ ನೀವು ಪಾವತಿಸುವುದು, **ತೆರಿಗೆಗೆ ಮೊದಲು** (ಸ್ಟಾಕ್‌ನ ವೆಚ್ಚ ಎಂದಿಗೂ ಖರೀದಿ ತೆರಿಗೆ ಒಳಗೊಂಡಿಲ್ಲ) |
| ಮಾರಾಟ ಬೆಲೆ | ಪ್ರತಿ ಘಟಕಕ್ಕೆ ನೀವು ವಿಧಿಸುವುದು. ಡೀಫಾಲ್ಟ್ ಆಗಿ ತೆರಿಗೆಗೆ ಮೊದಲು; **Prices include tax** ಆನ್ ಮಾಡಿದರೆ ತೆರಿಗೆ ಸೇರಿ |
| MRP | ಮುದ್ರಿತ ಗರಿಷ್ಠ ಬೆಲೆ, ಇದ್ದರೆ (ನಿಮ್ಮ ಬೆಲೆಯ ಪಕ್ಕದಲ್ಲಿ ಹೊಡೆದುಹಾಕಿದಂತೆ ತೋರಿಸಲಾಗುತ್ತದೆ) |
| ತೆರಿಗೆ ದರ % | ಈ ಉತ್ಪನ್ನದ GST ದರ. ಅದನ್ನು ಟೈಪ್ ಮಾಡಿ, ಅಥವಾ **Settings → Tax Configuration** ನಿಂದ ದರ ಕ್ಲಿಕ್ ಮಾಡಿ |
| ಮರುಆದೇಶ ಮಟ್ಟ / ಪ್ರಮಾಣ | ಕಡಿಮೆ-ಸ್ಟಾಕ್ ಎಚ್ಚರಿಕೆ ಎತ್ತುವ ಸ್ಟಾಕ್ ಮಟ್ಟ, ಮತ್ತು ನೀವು ಸಾಮಾನ್ಯವಾಗಿ ಎಷ್ಟು ಆದೇಶಿಸುತ್ತೀರಿ |
| ಆರಂಭಿಕ ಪ್ರಮಾಣ | ಉತ್ಪನ್ನ ಸೇರಿಸುವಾಗ ನಿಮ್ಮ ಬಳಿ ಈಗಾಗಲೇ ಇರುವ ಸ್ಟಾಕ್ |

**ನೀವು ಬೇರೆ ಹೇಳದ ಹೊರತು ಬೆಲೆಗಳು ತೆರಿಗೆಗೆ ಮೊದಲಿನವು.** ಡೀಫಾಲ್ಟ್ ಆಗಿ ನೀವು ಮಾರಾಟ ಅಥವಾ ಖರೀದಿಸುವಾಗ Sarang ಮೇಲೆ ತೆರಿಗೆ ಸೇರಿಸುತ್ತದೆ: ೧೮ ಪ್ರತಿಶತ ತೆರಿಗೆಯೊಂದಿಗೆ ೧೦೦ ಮಾರಾಟ ಬೆಲೆ ೧೧೮ ಕ್ಕೆ ಮಾರಾಟವಾಗುತ್ತದೆ. ನಿಮ್ಮ ಶೆಲ್ಫ್ ಬೆಲೆಯು ಈಗಾಗಲೇ ತೆರಿಗೆಯನ್ನು ಒಳಗೊಂಡಿದ್ದರೆ, **Prices include tax** ಆನ್ ಮಾಡಿ (Settings ನಲ್ಲಿ, ಅಥವಾ ಪ್ರತಿ ದಾಖಲೆಯಲ್ಲಿ ಸ್ವಿಚ್) ಮತ್ತು Sarang ತೆರಿಗೆಯನ್ನು ಹಿಂದಕ್ಕೆ ಲೆಕ್ಕ ಹಾಕುತ್ತದೆ, ಇದರಿಂದ ನೀವು ಕೈಯಿಂದ ಭಾಗಿಸಬೇಕಾಗಿಲ್ಲ. *ಮಾರ್ಗದರ್ಶಿ: ತೆರಿಗೆ ಮತ್ತು GST* ನೋಡಿ.

ನೀವು ಇಲ್ಲಿ ಹೊಂದಿಸುವ ತೆರಿಗೆ ದರವು ಉತ್ಪನ್ನವನ್ನು ಆಯ್ಕೆಮಾಡಿದಾಗ ಇನ್‌ವಾಯ್ಸ್‌ಗಳು, ಉದ್ಧರಣಗಳು, ಮಾರಾಟ ಆದೇಶಗಳು, ಖರೀದಿ ಆದೇಶಗಳು, ಪೂರೈಕೆದಾರರ ಬಿಲ್‌ಗಳು ಮತ್ತು ಡೆಬಿಟ್ ನೋಟ್‌ಗಳಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತುಂಬುತ್ತದೆ. ನೀವು ಇನ್ನೂ ಒಂದೇ ಸಾಲಿನಲ್ಲಿ ಅದನ್ನು ಬದಲಾಯಿಸಬಹುದು.

ವೇರಿಯಂಟ್‌ಗಳು (ಗಾತ್ರ ಮತ್ತು ಬಣ್ಣ), ತೂಕ-ಆಧಾರಿತ ಮಾರಾಟ, ಅವಧಿ ಮುಗಿಯುವ ಬ್ಯಾಚ್‌ಗಳು, ಸೀರಿಯಲ್ ಅಥವಾ IMEI ಸಂಖ್ಯೆಗಳು, ಮತ್ತು ಕಿಟ್‌ಗಳು (ಒಂದಾಗಿ ಮಾರಾಟವಾಗುವ ಹಲವಾರು ಉತ್ಪನ್ನಗಳು) ನಿಮ್ಮ ವ್ಯಾಪಾರ ಪ್ರಕಾರದಿಂದ ಅಥವಾ **Settings → Additional Business Features** ನಲ್ಲಿ ಆನ್ ಆಗುತ್ತವೆ.

## ೩. ಸ್ಟಾಕ್ ಒಳಗೆ ತರುವುದು

ಇವುಗಳಲ್ಲಿ ಒಂದು ಸಂಭವಿಸಿದಾಗ **ಮಾತ್ರ** ಸ್ಟಾಕ್ ಹೆಚ್ಚಾಗುತ್ತದೆ:

೧. ಅನುಮೋದಿತ ಖರೀದಿ ಆದೇಶದಲ್ಲಿ **Receive Stock**.
೨. ಉತ್ಪನ್ನಕ್ಕೆ ಲಿಂಕ್ ಆದ ಸಾಲಿನೊಂದಿಗಿನ **GRN** **ಪೋಸ್ಟ್ (Posted)** ಆಗುತ್ತದೆ.
೩. ಉತ್ಪನ್ನವನ್ನು ಮೊದಲ ಬಾರಿಗೆ ರಚಿಸುವಾಗ **ಆರಂಭಿಕ ಪ್ರಮಾಣ**.
೪. **ಸ್ಟಾಕ್ ಹೊಂದಾಣಿಕೆ** (ಕೆಳಗೆ).
೫. **ಮಾರಾಟ ರಿಟರ್ನ್** ಸರಕುಗಳನ್ನು ಹಿಂದಕ್ಕೆ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ, ಅಥವಾ **ಉತ್ಪಾದನಾ ಚಾಲನೆ** ಮುಗಿಯುತ್ತದೆ (ತಯಾರಕರು).

**ಪೂರೈಕೆದಾರರ ಬಿಲ್** ಒಂದೇ ಎಂದಿಗೂ ಸ್ಟಾಕ್ ಸೇರಿಸುವುದಿಲ್ಲ. *ಮಾರ್ಗದರ್ಶಿ: ಪೂರೈಕೆದಾರರಿಂದ ಖರೀದಿ* ನೋಡಿ.

## ೪. ಸ್ಟಾಕ್ ಹೊರಗೆ ತೆಗೆಯುವುದು

Billing ನಲ್ಲಿ ಮಾರಾಟವನ್ನು ಖಚಿತಪಡಿಸಿದಾಗ (ಅಥವಾ ಮಾರಾಟ ಆದೇಶ ಇನ್‌ವಾಯ್ಸ್ ಆದಾಗ), **ಡೆಬಿಟ್ ನೋಟ್** ಸರಕುಗಳನ್ನು ಹಿಂದಕ್ಕೆ ಕಳುಹಿಸಿದಾಗ, ಸರಕುಗಳನ್ನು ಉತ್ಪಾದನೆಯಲ್ಲಿ ಬಳಸಿದಾಗ, ಅಥವಾ ನೀವು ಅದನ್ನು ಕೆಳಗೆ ಹೊಂದಿಸಿದಾಗ ಸ್ಟಾಕ್ ಕಡಿಮೆಯಾಗುತ್ತದೆ.

ನಿಮ್ಮ ಬಳಿ ಇರುವುದಕ್ಕಿಂತ ಹೆಚ್ಚು ಮಾರಾಟ ಮಾಡಲು Sarang ಬಿಡುವುದಿಲ್ಲ. *Insufficient stock* ನೊಂದಿಗೆ ಮಾರಾಟ ತಡೆಹಿಡಿಯಲ್ಪಟ್ಟರೆ, ಮೊದಲು ಖರೀದಿ ಸ್ವೀಕರಿಸಿ ಅಥವಾ ಕಾರಣದೊಂದಿಗೆ ಸ್ಟಾಕ್ ಎಣಿಕೆ ಸರಿಪಡಿಸಿ. ಸರಕುಗಳು ದಾಖಲಾಗುವ ಮೊದಲು ನಿಜವಾಗಿಯೂ ಮಾರಾಟ ಮಾಡಬೇಕಾದರೆ, **Settings → Business Features → Stock rules** ನಲ್ಲಿ ಋಣಾತ್ಮಕ ಸ್ಟಾಕ್ ಆನ್ ಮಾಡಿ; ಸರಕುಗಳನ್ನು ಸ್ವೀಕರಿಸುವವರೆಗೆ ಪ್ರಮಾಣ ಶೂನ್ಯಕ್ಕಿಂತ ಕೆಳಗೆ ತೋರಿಸುತ್ತದೆ.

## ೫. ಸ್ಟಾಕ್ ಪರಿಶೀಲಿಸಿ ಮತ್ತು ಸರಿಪಡಿಸಿ

- **Inventory** ಪ್ರತಿ ಉತ್ಪನ್ನವನ್ನು ಪ್ರಸ್ತುತ ಪ್ರಮಾಣ, ಮರುಆದೇಶ ಮಟ್ಟ, ಸರಾಸರಿ ವೆಚ್ಚ ಮತ್ತು ಸ್ಟಾಕ್ ಮೌಲ್ಯದೊಂದಿಗೆ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. **Low Stock** ಟ್ಯಾಬ್ ಏನನ್ನು ಆದೇಶಿಸಬೇಕು ಎಂದು ತೋರಿಸುತ್ತದೆ.
- **ಸ್ಟಾಕ್ ಹೊಂದಿಸಿ**: ಸಾಲಿನಲ್ಲಿ ಹೊಂದಾಣಿಕೆ ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು **ಹೊಸ ಪ್ರಮಾಣ** ನಮೂದಿಸಿ (ವ್ಯತ್ಯಾಸವಲ್ಲ). ಕಾರಣ ನೀಡಿ (ಹಾನಿ, ಎಣಿಕೆ, ಆರಂಭಿಕ ಬಾಕಿ). ಸ್ಟಾಕ್ ಹೆಚ್ಚಿಸುವಾಗ ಸೇರಿಸಿದ ಘಟಕಗಳ ವೆಚ್ಚವನ್ನು ದಾಖಲಿಸಬಹುದು.
- **Movements** (Inventory ನಲ್ಲಿ ಬಟನ್) ಪ್ರತಿ ಬದಲಾವಣೆಯ ಓದಲು-ಮಾತ್ರ ಇತಿಹಾಸ: Stock Added, Sale, PO Received, Adjustment, Sale Return, ಮತ್ತು ಇನ್ನಷ್ಟು. "ಈ ಸಂಖ್ಯೆ ಏಕೆ ಹಾಗಿದೆ?" ಎಂಬುದಕ್ಕೆ ಉತ್ತರಿಸಲು ಇದನ್ನು ಬಳಸಿ.
- **ಸ್ಟಾಕ್ ಎಣಿಸುವುದು**: **Inventory → Stock Counts → New count**. ಪ್ರತಿ ಐಟಂಗೆ ನಿಮ್ಮ ಬಳಿ ಏನಿದೆ ಎಂದು ಅದು ಭಾವಿಸುತ್ತದೆ ಎಂಬುದರ ಸ್ನ್ಯಾಪ್‌ಶಾಟ್ ಅನ್ನು Sarang ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ; ನೀವು ನಿಜವಾಗಿ ಎಣಿಸಿದ್ದನ್ನು ಟೈಪ್ ಮಾಡುತ್ತೀರಿ, ಮತ್ತು ಅದು ವ್ಯತ್ಯಾಸ ಮತ್ತು ಅದರ ಮೌಲ್ಯವನ್ನು ತೋರಿಸುತ್ತದೆ. ನೀವು **Post** ಒತ್ತುವವರೆಗೆ ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ, ಇದು ಪ್ರತಿ ವ್ಯತ್ಯಾಸವನ್ನು ನಿಮ್ಮ ಮುಖ್ಯ ಸ್ಥಳದಲ್ಲಿ ಸ್ಟಾಕ್ ಹೊಂದಾಣಿಕೆಯಾಗಿ (ಕಾರಣ: ಸ್ಟಾಕ್ ಎಣಿಕೆ) ಬದಲಾಯಿಸುತ್ತದೆ. ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಎಣಿಕೆ ತೆರೆದಿರಬಹುದು. ಬ್ಯಾಚ್‌ಗಳು, ಸೀರಿಯಲ್ ಸಂಖ್ಯೆಗಳು ಅಥವಾ ಅವಧಿ ಮುಗಿಯುವಿಕೆ ಇರುವ ಐಟಂಗಳನ್ನು ಒಟ್ಟು ಪ್ರಮಾಣದಿಂದ ಮಾತ್ರ ಎಣಿಸಲಾಗುತ್ತದೆ. ಪೋಸ್ಟಿಂಗ್ ಅಡ್ಡಿಪಡಿಸಿದರೆ, ಎಣಿಕೆ ತೆರೆದಿರುತ್ತದೆ ಮತ್ತು ಈಗಾಗಲೇ ಪೋಸ್ಟ್ ಆದ ಸಾಲುಗಳು ಪೋಸ್ಟ್ ಆಗಿಯೇ ಉಳಿಯುತ್ತವೆ: ಉಳಿದದ್ದನ್ನು ಮುಗಿಸಲು ಮತ್ತೆ Post ಒತ್ತಿ. **Reports → Stock Count Variances** ಏನು ಕಡಿಮೆ ಅಥವಾ ಹೆಚ್ಚು ಇತ್ತು ಎಂದು ತೋರಿಸುತ್ತದೆ.
- **Stock Locations**: ಅಂಗಡಿ, ಗೋದಾಮು ಅಥವಾ ವ್ಯಾನ್‌ಗೆ ಪ್ರತ್ಯೇಕ ಸ್ಟಾಕ್ ಇಟ್ಟುಕೊಳ್ಳಿ, ಮತ್ತು ಅವುಗಳ ನಡುವೆ ಸ್ಟಾಕ್ ಸರಿಸಿ.
- **Bin Locations**: **Inventory → Bin Locations** ಒಂದು ಸ್ಥಳದೊಳಗೆ ಪ್ರತಿ ಐಟಂ ಯಾವ ಶೆಲ್ಫ್, ರ‍್ಯಾಕ್ ಅಥವಾ ಬಿನ್‌ನಲ್ಲಿದೆ (ಉದಾ. A-3-2) ಎಂದು ದಾಖಲಿಸುತ್ತದೆ, ಯಾರಾದರೂ ಅದನ್ನು ಕಂಡುಹಿಡಿಯಲು. ಇದು ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದ ಲೇಬಲ್: ಪ್ರತಿ ಸ್ಥಳದಲ್ಲಿ ಪ್ರತಿ ಐಟಂಗೆ ಒಂದು ಬಿನ್, ಮತ್ತು ಇದು ಈ ಪರದೆಯಲ್ಲಿ ಮಾತ್ರ ಕಾಣಿಸುತ್ತದೆ (ಇನ್ನೂ ವರದಿಗಳಲ್ಲಿ ಅಥವಾ ಮುದ್ರಿತ ಪಟ್ಟಿಗಳಲ್ಲಿ ಅಲ್ಲ).
- **Stock Journal**: **Inventory → Stock Journal** ಆಕಾರ ಬದಲಾಯಿಸುವ ಸರಕುಗಳನ್ನು ದಾಖಲಿಸುತ್ತದೆ, ಕಾರ್ಟನ್ ಅನ್ನು ಪ್ಯಾಕ್‌ಗಳಾಗಿ ಮುರಿಯುವಂತೆ: ಏನು ಹೊರಗೆ ಹೋಗುತ್ತದೆ ಮತ್ತು ಏನು ಒಳಗೆ ಬರುತ್ತದೆ ಎಂದು ಆಯ್ಕೆಮಾಡಿ ಮತ್ತು ಅವುಗಳನ್ನು ಒಟ್ಟಿಗೆ ಉಳಿಸಿ. ಹೊರಗೆ ಹೋಗುವ ಮೌಲ್ಯವನ್ನು ಪ್ರಮಾಣದ ಪ್ರಕಾರ ಒಳಗೆ ಬರುವ ಐಟಂಗಳ ಮೇಲೆ ಹರಡಲಾಗುತ್ತದೆ. ಉಳಿಸಿದ ನಂತರ ಇದನ್ನು ಸಂಪಾದಿಸಲು ಅಥವಾ ಹಿಂತಿರುಗಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ: ವಿರುದ್ಧ ಎಂಟ್ರಿಯೊಂದಿಗೆ ತಪ್ಪನ್ನು ಸರಿಪಡಿಸಿ.
- **ಆದೇಶಗಳಲ್ಲಿ ಭರವಸೆ ನೀಡಿದ್ದು**: **Inventory** ಮತ್ತು Stock Summary ವರದಿ ಪ್ರತಿ ಐಟಂ ಪಕ್ಕದಲ್ಲಿ, ತೆರೆದ ಮಾರಾಟ ಆದೇಶಗಳಲ್ಲಿ ಎಷ್ಟು ಭರವಸೆ ನೀಡಲಾಗಿದೆ ಎಂದು ತೋರಿಸುತ್ತವೆ. ಇದು ಒಂದು ಜ್ಞಾಪನೆ, ತಡೆಯಲ್ಲ: ಭರವಸೆ ನೀಡಿದ ಸ್ಟಾಕ್ ಮಾರಾಟ ಮಾಡುವುದನ್ನು ಏನೂ ತಡೆಯುವುದಿಲ್ಲ.

## ೬. ಖಾಲಿಯಾಗುವ ಮೊದಲು ಮರುಆದೇಶಿಸಿ

- ಪ್ರತಿ ಉತ್ಪನ್ನದಲ್ಲಿ **ಮರುಆದೇಶ ಮಟ್ಟ** ಹೊಂದಿಸಿ.
- **Dashboard** ನಲ್ಲಿ ಕಡಿಮೆ-ಸ್ಟಾಕ್ ಟೈಲ್‌ಗಳು ಮತ್ತು ಬೆಲ್ ಎಚ್ಚರಿಕೆಗಳನ್ನು ಗಮನಿಸಿ. ಕಡಿಮೆ-ಸ್ಟಾಕ್ ಎಚ್ಚರಿಕೆ ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ **Inventory** ತೆರೆಯುತ್ತದೆ.
- **Inventory** ಪರದೆಯಲ್ಲಿ, **Generate Reorder POs** ಪ್ರತಿ ಉತ್ಪನ್ನದ ಡೀಫಾಲ್ಟ್ ಪೂರೈಕೆದಾರರನ್ನು ಬಳಸಿ ಅದರ ಮರುಆದೇಶ ಮಟ್ಟಕ್ಕಿಂತ ಕೆಳಗಿರುವ ಎಲ್ಲದಕ್ಕೂ ಡ್ರಾಫ್ಟ್ ಖರೀದಿ ಆದೇಶಗಳನ್ನು ರಚಿಸುತ್ತದೆ (ಮೊದಲು ಉತ್ಪನ್ನದಲ್ಲಿ ಡೀಫಾಲ್ಟ್ ಪೂರೈಕೆದಾರರನ್ನು ಹೊಂದಿಸಿ).

## ೭. ನನ್ನ ಸ್ಟಾಕ್‌ನ ಮೌಲ್ಯ ಎಷ್ಟು?

**Inventory** ಪ್ರತಿ ಉತ್ಪನ್ನದ ಮೌಲ್ಯವನ್ನು ತೋರಿಸುತ್ತದೆ (ಪ್ರಮಾಣ x ಸರಾಸರಿ ವೆಚ್ಚ). **Reports → Stock Summary**, **Stock Ledger** (ಆರಂಭ ಮತ್ತು ಅಂತ್ಯದೊಂದಿಗೆ ಪ್ರತಿ ಚಲನೆ), **Inventory Ageing**, ಮತ್ತು ಸ್ಥಳ-ಪ್ರಕಾರ ಮತ್ತು ವರ್ಗಾವಣೆ ವರದಿಗಳು ಮೌಲ್ಯಮಾಪನ, ಚಲನೆ, ಮತ್ತು ಐಟಂಗಳು ಎಷ್ಟು ಸಮಯದಿಂದ ಕುಳಿತಿವೆ ಎಂದು ತೋರಿಸುತ್ತವೆ. ಮೌಲ್ಯಮಾಪನವು ನೀವು ಬಳಸುವ ವಿಧಾನವನ್ನು ಅನುಸರಿಸುತ್ತದೆ (ಸರಾಸರಿ, FIFO ಮತ್ತು ಆನ್ ಆಗಿರುವಲ್ಲಿ ಇತರೆ) ಮತ್ತು ಪ್ರತಿ ವರದಿ ಇಂದಿನ ದಿನಾಂಕದಂತೆ ಎಂದು ಹೇಳುತ್ತದೆ. ಖರೀದಿಯಲ್ಲಿ **ಲ್ಯಾಂಡೆಡ್ ಕಾಸ್ಟ್** ಆಗಿ ನಮೂದಿಸಿದ ಫ್ರೈಟ್ ಅಥವಾ ಸುಂಕದ ವೆಚ್ಚಗಳು ಆ ಐಟಂಗಳ ವೆಚ್ಚವನ್ನು ಹೆಚ್ಚಿಸುತ್ತವೆ.
