# માર્ગદર્શિકા: રોજની, અઠવાડિયાની અને મહિનાની દિનચર્યા

એક ચેકલિસ્ટ જે તમે વિચાર્યા વગર અનુસરી શકો. તમારા ધંધાને જે લાગુ પડે તેના પર નિશાન કરો.

## દરરોજ (૧૦ મિનિટ)

**સવારે**
- **ડૅશબૉર્ડ** ખોલો. ચેતવણીઓ (ઓછો સ્ટૉક, લેણાં, બાકી રિમાઇન્ડર) અને ગઈકાલનું વેચાણ જુઓ. **Customise** (ઉપર જમણે) તમે ન વાપરતા ભાગ છુપાવે છે, અને **Add your own tile** તમને મહત્ત્વનો આંકડો બતાવે છે, જેમ કે આ અઠવાડિયાનો ખર્ચ; બંને આ કમ્પ્યુટર પર તમારા લૉગિન માટે યાદ રહે છે.
- **ઘંટડી** પર ક્લિક કરો. દરેક ચેતવણી જે વિશે છે તે સ્ક્રીન ખોલે છે.
- **WhatsApp Reminders**: આજે બાકી હોય તે મોકલો (*Guide: Reminders and Alerts* જુઓ).
- Ask Sarang: "મારું ધ્યાન શેના પર જોઈએ?"

**દિવસ દરમિયાન**
- **બિલિંગ** માં વેચો. બીજો ગ્રાહક આવે તો વેચાણ હોલ્ડ કરો.
- ચુકવણી આવે ત્યારે નોંધો (ઇન્વૉઇસ સ્ક્રીન → Record Payment).
- માલ આવે ત્યારે ખરીદ ઓર્ડર પર **Receive Stock** કરો (અથવા દરેક લીટીને ઉત્પાદન સાથે જોડીને GRN પોસ્ટ કરો).

**બંધ કરતી વખતે**
- **Accounting → કૅશ ક્લોઝ**: રોકડ ગણો, Sarang જે અપેક્ષા રાખે છે તેની સાથે સરખાવો, અને તફાવત નોંધો.
- દિવસનો **અહેવાલ → Sales** તપાસો.

## દર અઠવાડિયે

- **અહેવાલ → Outstanding**: કોણ કેટલા સમયથી તમારા દેણદાર છે. સૌથી જૂનાને રિમાઇન્ડર મોકલો.
- **Purchases → Purchases Overview**: આગામી ૭ દિવસમાં ચૂકવવાના બિલ. **Supplier Bills → Overdue** ફિલ્ટર; ચુકવણીનું આયોજન કરો. આ અઠવાડિયે કરેલી સપ્લાયર ચુકવણી નોંધો.
- **ભંડાર → Low Stock**: ખરીદ ઓર્ડર બનાવો (અથવા ભંડાર સ્ક્રીન પર **Generate Reorder POs** વાપરો).
- **ભાવપત્રક → Expired** ફિલ્ટર: સમાપ્ત થયેલાનો પીછો કરો અથવા બંધ કરો.
- તમે શું ખરીદ્યું તે જોવા **અહેવાલ → Purchase Register** જુઓ.
- સ્વચાલિત બૅકઅપ ન વાપરતા હો તો બૅકઅપ લો (સેટિંગ, બૅકઅપ).

## દર મહિને

- મહિના માટે **અહેવાલ → Profit and Loss** અને **Trial Balance**.
- **અહેવાલ → Tax Report / GSTR-1 / GSTR-3B Preview / GST Net Payable & Input Credit** (અથવા ભારત બહાર **VAT / Sales Tax Return**) તમારા એકાઉન્ટન્ટને મોકલો, અથવા રિટર્ન તૈયાર કરવા વાપરો. GST ધરાવતા ધંધા **Accounting → GST Return Files** માં GSTR-1 અને GSTR-3B ફાઇલ તૈયાર કરી શકે છે અને ખરીદીને પોર્ટલના GSTR-2B સાથે મેળવી શકે છે.
- **Bank Account** ને બૅંક સ્ટેટમેન્ટ સાથે મેળવો (**Accounting → Bank Accounts** માં બૅંક ખાતું ખોલો, પછી **Reconciliation**).
- **Supplier Payments** ને સપ્લાયર જે કહે છે કે તમારે આપવાના છે તેની સાથે તપાસો (દરેક મોટા સપ્લાયરનું પાનું ખોલો).
- પગાર ચલાવો (**People & Payroll → પગારપત્રક**) અને સ્ટાફની હાજરી અને રજા નોંધો.
- મહિનાના **ખર્ચ** તપાસો અને રસીદો સાથે મેળવો.
- ઝડપથી વેચાતી થોડી વસ્તુઓ ગણો અને તફાવત **Adjust stock** થી સુધારો, અથવા તફાવત અહેવાલ જોઈતો હોય તો પૂરું **Stock Counts** સત્ર ચલાવો.
- સ્ટાફે આપેલા **expense claims** નોંધો, મંજૂર કરો અને પાછા ચૂકવો.
- **Balance Sheet** મેળ ખાય છે કે નહીં તે તપાસો અને Ask Sarang ને પૂછો "મારા ચોપડા મેળ ખાય છે?".
- **બૅકઅપ** લો અને એક નકલ બીજી ડ્રાઇવ અથવા પેન ડ્રાઇવ પર રાખો.

## દર વર્ષે

- તમારા એકાઉન્ટન્ટ ખાતરી કરે પછી પૂરું થયેલું વર્ષ લૉક કરો (Ledger Settings, લૉક તારીખ).
- **Fixed Assets અને વર્ષાંત ક્લોઝ**: ઘસારો પોસ્ટ કરો અને વર્ષ બંધ કરો (તે પ્રકરણ જુઓ).
- Sarang લાઇસન્સ પૂરું થાય તે પહેલાં રિન્યૂ કરો (સેટિંગ → લાઇસન્સ). પૂરું થાય તો પણ તમે બધું જોઈ, છાપી, એક્સપોર્ટ અને બૅકઅપ કરી શકો છો; ફક્ત નવા બિલ અટકે છે.
- જેમની સાથે હવે વ્યવહાર નથી તે ગ્રાહકો અને સપ્લાયર આર્કાઇવ કરો.

## જ્યારે કંઈક ખોટું લાગે

| તમે જુઓ છો | પહેલા અહીં જુઓ |
|---|---|
| ગ્રાહક કહે છે ચૂકવ્યું, પણ ઇન્વૉઇસ ન ચૂકવાયેલું દેખાય છે | **Payment History** (ઇન્વૉઇસ કે સંદર્ભ શોધો) |
| સ્ટૉક છાજલી કરતાં અલગ છે | તે ઉત્પાદનનું **ભંડાર → Movements**, પછી કારણ સાથે સમાયોજિત કરો |
| સપ્લાયરનું બાકી તેઓ કહે છે તેવું નથી | સપ્લાયરનું પાનું: બિલ, ચુકવણી, ડેબિટ નોટ; ખોટા બિલ પર ચુકવણી નોંધાઈ છે કે નહીં તપાસો |
| બિલની રકમ ખોટી છે | તેને ખોલો અને **Edit bill** કરો (ફક્ત જ્યાં સુધી તે ખુલ્લું અને ન ચૂકવાયેલું હોય) |
| વેચાણ ખોટા ભાવે ગયું | **Cancel Invoice** કરીને ફરી બિલ બનાવો, અથવા તફાવત માટે **ક્રેડિટ નોટ** આપો |
| કર ખોટો લાગે છે | ઉત્પાદનનો **Tax Rate %**, પછી દસ્તાવેજની લીટી |
| અહેવાલનો કોઈ આંકડો વિચિત્ર લાગે | અહેવાલની હરોળથી તેની પાછળના દસ્તાવેજ સુધી ક્લિક કરતા જાઓ |
