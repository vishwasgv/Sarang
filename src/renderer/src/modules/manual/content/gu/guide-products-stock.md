# માર્ગદર્શિકા: પ્રોડક્ટ્સ, કેટેગરી અને સ્ટોક

તમે જે વેચો છો તે કેવી રીતે સેટ કરવું, સ્ટોક બરાબર રાખવો, અને કોઈ આંકડો કેમ તેવો છે તે શોધવું.

## ૧. પહેલાં કેટેગરી (૨ મિનિટ, કલાકો બચાવે છે)

કેટેગરી ફિલ્ટરિંગ અને રિપોર્ટ માટે પ્રોડક્ટ્સને જૂથબદ્ધ કરે છે (દા.ત. *બલ્બ*, *સ્વિચ*, *વાયર*).

- **Inventory → પ્રોડક્ટ્સ → કેટેગરી બટન** **Manage Categories** ખોલે છે: ઉમેરો, નામ બદલો, સબ-કેટેગરી ઉમેરો, કે આર્કાઇવ કરો.
- **પ્રોડક્ટ બનાવતી વખતે ઝડપી ઉમેરો**: પ્રોડક્ટ ફોર્મમાં, **+ Create new category…** પસંદ કરો, નામ ટાઇપ કરો (સબ-કેટેગરી હોય તો પેરેન્ટ પણ) અને તે તરત બની અને પસંદ થાય છે.

## ૨. પ્રોડક્ટ ઉમેરો

**Inventory → પ્રોડક્ટ્સ → Add Product.**

| ફીલ્ડ | શું દાખલ કરવું |
|---|---|
| પ્રોડક્ટનું નામ | તમે અને તમારા ગ્રાહકો તેને શું કહે છે |
| SKU / બારકોડ | તમારો પોતાનો કોડ, અથવા ઉત્પાદકનો બારકોડ સ્કેન કરો |
| HSN કોડ | તમારો એકાઉન્ટન્ટ આપે તે માલ વર્ગીકરણ કોડ (સેવાઓ માટે SAC) |
| પ્રોડક્ટ પ્રકાર | **Standard** (સ્ટોક ગણાય છે) કે **Service** (સ્ટોક નહીં, દા.ત. મજૂરી) |
| એકમ | PCS, KG, L, M, BOX વગેરે |
| કોસ્ટ પ્રાઇસ | એકમ દીઠ તમે ચૂકવો છો, **કર પહેલાં** (સ્ટોકની કિંમતમાં ખરીદ કર ક્યારેય સામેલ નથી) |
| સેલિંગ પ્રાઇસ | એકમ દીઠ તમે લો છો. ડિફોલ્ટ કર પહેલાં; **Prices include tax** ચાલુ કરો તો કર સહિત |
| MRP | છાપેલી મહત્તમ કિંમત, જો હોય (તમારી કિંમતની બાજુમાં કાપેલી બતાવાય છે) |
| કર દર % | આ પ્રોડક્ટનો GST દર. તે ટાઇપ કરો, અથવા **Settings → Tax Configuration** માંથી દર ક્લિક કરો |
| રીઓર્ડર લેવલ / જથ્થો | જે સ્ટોક લેવલે લો-સ્ટોક એલર્ટ આવે, અને તમે સામાન્ય રીતે કેટલું મંગાવો છો |
| ઓપનિંગ જથ્થો | પ્રોડક્ટ ઉમેરતી વખતે તમારી પાસે પહેલેથી જે સ્ટોક છે |

**ખાસ ન કહો ત્યાં સુધી કિંમતો કર પહેલાંની છે.** ડિફોલ્ટ રીતે વેચતી કે ખરીદતી વખતે Sarang ઉપરથી કર ઉમેરે છે: ૧૮ ટકા કર સાથે ૧૦૦ ની સેલિંગ પ્રાઇસ ૧૧૮ માં વેચાય છે. જો તમારી શેલ્ફ કિંમતમાં પહેલેથી કર સામેલ હોય, તો **Prices include tax** ચાલુ કરો (Settings માં, અથવા દરેક દસ્તાવેજ પર સ્વિચ) અને Sarang કર પાછળથી કાઢી આપે છે, જેથી તમારે હાથે ભાગવું ન પડે. *માર્ગદર્શિકા: કર અને GST* જુઓ.

તમે અહીં સેટ કરેલો કર દર પ્રોડક્ટ પસંદ કરતાં ઇન્વોઇસ, ક્વોટેશન, સેલ્સ ઓર્ડર, ખરીદ ઓર્ડર, સપ્લાયર બિલ અને ડેબિટ નોટમાં આપોઆપ ભરાય છે. તમે એક લાઇન પર તેને હજુ પણ બદલી શકો છો.

વેરિયન્ટ (સાઇઝ અને રંગ), વજન-આધારિત વેચાણ, એક્સપાયરી સાથેના બેચ, સિરિયલ કે IMEI નંબર, અને કિટ્સ (એક તરીકે વેચાતા અનેક પ્રોડક્ટ્સ) તમારા બિઝનેસ પ્રકાર દ્વારા કે **Settings → Additional Business Features** માં ચાલુ થાય છે.

## ૩. સ્ટોક અંદર લાવો

આમાંથી એક થાય ત્યારે **જ** સ્ટોક વધે છે:

૧. મંજૂર થયેલા ખરીદ ઓર્ડર પર **Receive Stock**.
૨. પ્રોડક્ટ સાથે લિંક કરેલી લાઇનવાળો **GRN** **પોસ્ટ (Posted)** થાય.
૩. પ્રોડક્ટ પહેલી વાર બનાવો ત્યારે **ઓપનિંગ જથ્થો**.
૪. **સ્ટોક એડજસ્ટમેન્ટ** (નીચે).
૫. **સેલ્સ રિટર્ન** માલ પાછો લે, અથવા **પ્રોડક્શન રન** પૂરો થાય (ઉત્પાદકો).

એકલું **સપ્લાયર બિલ** ક્યારેય સ્ટોક ઉમેરતું નથી. *માર્ગદર્શિકા: સપ્લાયર પાસેથી ખરીદી* જુઓ.

## ૪. સ્ટોક બહાર કાઢો

Billing માં વેચાણ કન્ફર્મ કરો (કે Sales Order ઇન્વોઇસ થાય), **Debit Note** માલ પાછો મોકલે, પ્રોડક્શનમાં માલ વપરાય, કે તમે તેને ઘટાડો ત્યારે સ્ટોક ઘટે છે.

Sarang તમારી પાસે છે તેનાથી વધુ વેચવા દેશે નહીં. *Insufficient stock* સાથે વેચાણ બ્લોક થાય તો, પહેલાં ખરીદી સ્વીકારો અથવા કારણ સાથે સ્ટોક ગણતરી સુધારો. જો માલ નોંધાય તે પહેલાં ખરેખર વેચવાની જરૂર હોય, તો **Settings → Business Features → Stock rules** માં નેગેટિવ સ્ટોક ચાલુ કરો; જથ્થો ત્યારે માલ ન મળે ત્યાં સુધી શૂન્યથી નીચે બતાવાય છે.

## ૫. સ્ટોક તપાસો અને સુધારો

- **Inventory** દરેક પ્રોડક્ટને વર્તમાન જથ્થો, રીઓર્ડર લેવલ, સરેરાશ કોસ્ટ અને સ્ટોક વેલ્યુ સાથે યાદી કરે છે. **Low Stock** ટેબ શું મંગાવવાની જરૂર છે તે બતાવે છે.
- **સ્ટોક એડજસ્ટ કરો**: લાઇન પર એડજસ્ટ આઇકોન ક્લિક કરો અને **નવો જથ્થો** દાખલ કરો (ફેર નહીં). કારણ આપો (નુકસાન, ગણતરી, ઓપનિંગ બેલેન્સ). સ્ટોક વધારતી વખતે તમે ઉમેરેલા યુનિટ્સની કિંમત નોંધી શકો છો.
- **Movements** (Inventory પર બટન) દરેક ફેરફારનો ફક્ત-વાંચવા યોગ્ય ઇતિહાસ છે: Stock Added, Sale, PO Received, Adjustment, Sale Return, અને વધુ. "આ આંકડો કેમ તેવો છે?" નો જવાબ આપવા તેનો ઉપયોગ કરો.
- **સ્ટોક ગણવો**: **Inventory → Stock Counts → New count**. Sarang દરેક આઇટમ માટે તમારી પાસે શું છે તેનો સ્નેપશોટ લે છે; તમે ખરેખર જે ગણ્યું તે ટાઇપ કરો, અને તે ફેર અને તેની કિંમત બતાવે છે. **Post** દબાવો ત્યાં સુધી કંઈ બદલાતું નથી, જે દરેક ફેરને તમારા મુખ્ય લોકેશન પર સ્ટોક એડજસ્ટમેન્ટ (કારણ: સ્ટોક ગણતરી) માં ફેરવે છે. એક સમયે ફક્ત એક જ ગણતરી ખુલ્લી હોઈ શકે. બેચ, સિરિયલ નંબર કે એક્સપાયરીવાળી આઇટમ ફક્ત કુલ જથ્થાથી ગણાય છે. પોસ્ટિંગ અટકે તો, ગણતરી ખુલ્લી રહે છે અને પહેલેથી પોસ્ટ થયેલી લાઇન પોસ્ટ રહે છે: બાકી પૂરું કરવા ફરી Post દબાવો. **Reports → Stock Count Variances** શું ખૂટતું કે વધારે હતું તે બતાવે છે.
- **Stock Locations**: દુકાન, ગોડાઉન કે વાન માટે અલગ સ્ટોક રાખો, અને તેમની વચ્ચે સ્ટોક ખસેડો.
- **Bin Locations**: **Inventory → Bin Locations** લોકેશનમાં દરેક આઇટમ કયા શેલ્ફ, રેક કે બિનમાં (દા.ત. A-3-2) છે તે નોંધે છે, જેથી કોઈ પણ તે શોધી શકે. તે હાથે ટાઇપ કરેલું લેબલ છે: લોકેશન દીઠ આઇટમ દીઠ એક બિન, અને તે ફક્ત આ સ્ક્રીન પર દેખાય છે (હજુ રિપોર્ટ કે પ્રિન્ટેડ યાદીમાં નહીં).
- **Stock Journal**: **Inventory → Stock Journal** આકાર બદલતા માલની નોંધ કરે છે, જેમ કે કાર્ટન તોડીને પેક બનાવવા: શું બહાર જાય અને શું અંદર આવે તે પસંદ કરી સાથે સાચવો. બહાર જતી કિંમત જથ્થા પ્રમાણે અંદર આવતી આઇટમ પર વહેંચાય છે. સાચવ્યા પછી તે એડિટ કે ઉલટાવી શકાતું નથી: વિરુદ્ધ એન્ટ્રીથી ભૂલ સુધારો.
- **ઓર્ડર પર વચન અપાયેલ**: **Inventory** અને Stock Summary રિપોર્ટ દરેક આઇટમની બાજુમાં બતાવે છે કે ખુલ્લા Sales Orders પર કેટલું વચન અપાયું છે. તે યાદ અપાવે છે, રોકતું નથી: વચન અપાયેલો સ્ટોક વેચતાં કંઈ રોકતું નથી.

## ૬. ખૂટે તે પહેલાં રીઓર્ડર કરો

- દરેક પ્રોડક્ટ પર **રીઓર્ડર લેવલ** સેટ કરો.
- **Dashboard** પર લો-સ્ટોક ટાઇલ્સ અને બેલ એલર્ટ જુઓ. લો-સ્ટોક એલર્ટ ક્લિક કરતાં **Inventory** ખૂલે છે.
- **Inventory** સ્ક્રીન પર, **Generate Reorder POs** દરેક પ્રોડક્ટના ડિફોલ્ટ સપ્લાયરનો ઉપયોગ કરી રીઓર્ડર લેવલથી નીચેની દરેક વસ્તુ માટે ડ્રાફ્ટ ખરીદ ઓર્ડર બનાવે છે (પહેલાં પ્રોડક્ટ પર ડિફોલ્ટ સપ્લાયર સેટ કરો).

## ૭. મારો સ્ટોક કેટલો કિંમતી છે?

**Inventory** દરેક પ્રોડક્ટની કિંમત બતાવે છે (જથ્થો x સરેરાશ કોસ્ટ). **Reports → Stock Summary**, **Stock Ledger** (ઓપનિંગ અને ક્લોઝિંગ સાથે દરેક હિલચાલ), **Inventory Ageing**, અને લોકેશન-પ્રમાણે અને ટ્રાન્સફર રિપોર્ટ વેલ્યુએશન, હિલચાલ અને આઇટમ કેટલા સમયથી પડી છે તે બતાવે છે. વેલ્યુએશન તમે વાપરો છો તે પદ્ધતિ પ્રમાણે (સરેરાશ, FIFO અને ચાલુ હોય ત્યાં અન્ય) અનુસરે છે અને દરેક રિપોર્ટ કહે છે કે તે આજની તારીખ પ્રમાણે છે. ખરીદી પર **લેન્ડેડ કોસ્ટ** તરીકે દાખલ કરેલ ફ્રેટ કે ડ્યુટી ખર્ચ તે આઇટમની કિંમત વધારે છે.
