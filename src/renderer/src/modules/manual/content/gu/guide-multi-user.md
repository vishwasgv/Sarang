# માર્ગદર્શિકા: એક કરતાં વધુ કમ્પ્યુટર પર Sarang વાપરવું

કેટલીક દુકાનોમાં બે-ત્રણ જણને એક સાથે કામ કરવું પડે છે: એક કાઉન્ટર પર, એક ખરીદી સંભાળે, એક હિસાબ તપાસે. Sarang આ તમારી પોતાની દુકાનના નેટવર્ક પર કરી શકે છે. ઇન્ટરનેટ પર કંઈ જતું નથી.

## તે કેવી રીતે કામ કરે છે

- એક કમ્પ્યુટર બધો ડેટા રાખે છે. તેને **સર્વર** કહે છે. દુકાનના સમય દરમિયાન તેને ચાલુ રાખો અને Sarang ખુલ્લું રાખો.
- બાકીના કમ્પ્યુટર **ક્લાયન્ટ** છે. તેમાં ધંધાનો ડેટા રહેતો નથી. તેઓ સર્વર પર રાખેલો ડેટા બતાવે અને બદલે છે.
- કમ્પ્યુટરો વચ્ચે જે કંઈ જાય છે તે તમે પસંદ કરેલા **સહિયારા ગુપ્ત કોડ**થી એન્ક્રિપ્ટ થાય છે. તમે ચાલુ ન કરો ત્યાં સુધી તે બંધ રહે છે.

## તમને શું જોઈએ

- બધા કમ્પ્યુટર દુકાનના એક જ નેટવર્ક પર (એક જ Wi-Fi અથવા એક જ કેબલ નેટવર્ક).
- પૂરતી **બેઠકો** ધરાવતું લાઇસન્સ. દુકાનનું કમ્પ્યુટર એક બેઠક ગણાય છે, અને એક સાથે સાઇન ઇન થયેલ દરેક બીજું કમ્પ્યુટર વધુ એક બેઠક વાપરે છે. મફત ટ્રાયલમાં બે કમ્પ્યુટરની છૂટ છે જેથી તમે અજમાવી શકો. બેઠકો ઉમેરવા લાઇસન્સ સ્ક્રીન પર આપેલા સરનામે લખો.

## સર્વર સેટ કરો (જે કમ્પ્યુટર ડેટા રાખે છે)

1. માલિક તરીકે સાઇન ઇન કરો. **Settings → Business features → Multi-user** પર જાઓ.
2. **આ કમ્પ્યુટર ડેટા રાખે છે (સર્વર)** પસંદ કરો.
3. બતાવેલું **સરનામું** (જેમ કે 192.168.1.10:47821) અને **સહિયારો ગુપ્ત કોડ** લખી લો. ગુપ્ત કોડ તમે ગમે ત્યારે **નવો ગુપ્ત કોડ બનાવો** થી બદલી શકો છો.
4. **સાચવો અને Sarang ફરી શરૂ કરો** દબાવો.
5. જો બીજું કમ્પ્યુટર જોડાઈ ન શકે, તો આ કમ્પ્યુટરના Windows ફાયરવોલમાં ખાનગી નેટવર્ક માટે Sarang ને મંજૂરી આપો.

## દરેક ક્લાયન્ટ કમ્પ્યુટર સેટ કરો

1. કમ્પ્યુટર પર Sarang ઇન્સ્ટૉલ કરીને ખોલો.
2. સાઇન ઇન પાના પર **કમ્પ્યુટર જોડાણ સેટિંગ્સ (ઘણા કમ્પ્યુટર)** દબાવો.
3. **આ કમ્પ્યુટર બીજા કમ્પ્યુટર સાથે જોડાય છે (ક્લાયન્ટ)** પસંદ કરો. સર્વરનું સરનામું અને સહિયારો ગુપ્ત કોડ લખો, **જોડાણ ચકાસો** દબાવો, પછી **સાચવો અને Sarang ફરી શરૂ કરો**.
4. તમારા પોતાના યુઝરનેમ અને પાસવર્ડથી સાઇન ઇન કરો. **Settings → Users** માં દરેક વ્યક્તિ માટે યુઝરનેમ બનાવો જેથી દરેક વેચાણ અને ફેરફાર પર દેખાય કે કોણે કર્યું.

## સાથે કામ કરવું

- દરેકનું પોતાનું સાઇન ઇન અને પોતાની પરવાનગીઓ હોય છે.
- જો બે જણ બરાબર એક જ ક્ષણે સાચવે, તો એક જણ થોડી વાર બીજાની રાહ જુએ છે. ઇન્વૉઇસ નંબર જેવા નંબર ક્યારેય પુનરાવર્તિત થતા નથી. જો બે જણ છેલ્લું યુનિટ વેચે, તો ફક્ત એક જ વેચાણ પૂરું થાય છે.
- જ્યારે કોઈ ગ્રાહક, સપ્લાયર અથવા ઉત્પાદન બદલવા ખોલે, ત્યારે એ જ રેકૉર્ડ ખોલનારા બીજાને **"… એ આ બીજા કમ્પ્યુટર પર ખોલ્યું છે"** દેખાય છે અને તે બંધ ન થાય ત્યાં સુધી તેઓ સાચવી શકતા નથી.
- જ્યારે બીજું કમ્પ્યુટર ડેટા બદલે, ત્યારે એક નાની નોંધ આવે છે: **"… એ બીજા કમ્પ્યુટર પર થોડો ડેટા બદલ્યો. તાજું કરો."** નવું જોવા તાજું કરો દબાવો.
- સર્વર પરનું **Settings → Business features → Multi-user** કોણ જોડાયેલું છે તે બતાવે છે અને કોઈ કમ્પ્યુટરને ડિસ્કનેક્ટ કરવા દે છે.

## જે ફક્ત સર્વર કમ્પ્યુટર પર ચાલે છે

બૅકઅપ અને રિસ્ટોર, ફાઇલો આયાત કરવી, ટ્યુટોરિયલ, લાઇસન્સ ચાલુ કરવું, ડિસ્કમાંથી દસ્તાવેજ ખોલવા અને રસોડાની ચિઠ્ઠી છાપવી સર્વર કમ્પ્યુટર પર થાય છે. ક્લાયન્ટ કમ્પ્યુટર ઇન્વૉઇસ પોતાના પ્રિન્ટર પર છાપે છે અને અહેવાલ (Excel, PDF, CSV) પોતાની ડિસ્ક પર સાચવે છે.

## સારી ટેવો

- સર્વરને સ્થિર વીજળી પર રાખો અને સર્વર પર રોજ બૅકઅપ લો. સર્વર બંધ હોય તો ક્લાયન્ટ કામ કરી શકતા નથી.
- ડેટા ફાઇલ બીજા કમ્પ્યુટર પર કૉપી ન કરો અને એક જ ફાઇલ નેટવર્ક પરથી બે કમ્પ્યુટરથી ન ખોલો. તેના બદલે આ જ સુવિધા વાપરો. એક ફાઇલ બે કમ્પ્યુટરથી ખોલવાથી તે બગડી શકે છે.
- સહિયારો ગુપ્ત કોડ ખાનગી રાખો. જો કોઈ દુકાન છોડી દે, તો **નવો ગુપ્ત કોડ બનાવો** દબાવો અને નવો કોડ બીજા કમ્પ્યુટર પર લખો.
